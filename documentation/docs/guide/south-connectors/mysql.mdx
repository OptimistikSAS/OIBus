# MySQL® / MariaDB™

Connect to and query MySQL® or MariaDB™ databases with OIBus.

:::info Compatibility Notes

- Supports MySQL 5.7+
- Supports MariaDB 10.2+

:::

## Specific Settings {#specific-settings}

| Setting            | Description                                                            | Example Value  |
| ------------------ | ---------------------------------------------------------------------- | -------------- |
| Host               | IP address or hostname of the MySQL/MariaDB server.                    | `192.168.1.10` |
| Port               | Server port number. Default: `3306`.                                   | `3306`         |
| Connection timeout | Maximum time in milliseconds to establish connection. Default: `5000`. | `5000`         |
| Database           | Name of the database to connect to.                                    | `production`   |
| Username           | Authentication username.                                               | `db_user`      |
| Password           | Authentication password.                                               | `••••••••`     |

:::caution User Permissions

Always use a read-only database user

:::

## Exploring Tables {#exploring-tables}

Click **Explore** to browse the database's tables (with their column count and, where the database gives it, an
approximate row count) and the columns of each table, with their type and, where available, nullability, primary key
and default value. Check tables or columns and click
**Add as items** to create one item per table, whose query reads the checked columns and is tracked on a date/time
column picked automatically — see [SQL Tables as Items](./common-settings.md#sql-tables-as-items).

An [items synchronisation](./common-settings.md#items-synchronisation) on this connector runs a metadata query and
pushes its rows to OIAnalytics; it never creates items.

:::note MySQL / MariaDB datetime field types
The following **Type** values are available for the tracking instant's datetime field:

| Type            | Description                                       |
| --------------- | ------------------------------------------------- |
| String          | String representation parsed with a custom format |
| DateTime        | MySQL `DATETIME` or `TIMESTAMP` column            |
| ISO String      | ISO 8601 string (e.g. `2024-01-15T10:30:00.000Z`) |
| UNIX epoch (s)  | Unix timestamp in seconds                         |
| UNIX epoch (ms) | Unix timestamp in milliseconds                    |

:::

:::note MySQL item request timeout
Each MySQL item has its own **Request timeout** field (milliseconds), setting the maximum execution time for that
item's query. There is no connection-level equivalent to override — **Connection timeout** only bounds how long
OIBus waits to establish the connection itself, not how long a query may run.
:::
