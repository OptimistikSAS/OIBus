# MQTT

MQTT (Message Queuing Telemetry Transport) is a lightweight protocol designed for real-time messaging using a
publish/subscribe model. OIBus acts as an MQTT client using the [MQTT.js](https://github.com/mqttjs/MQTT.js) library to
interact with MQTT brokers.

## Specific Settings {#specific-settings}

### Connection {#connection}

| Setting                       | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Example Value                    |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| URL                           | Address of the MQTT broker. Accepts `mqtt://`, `mqtts://`, `tcp://`, `tls://`, `ws://`, or `wss://` (use `mqtts://`/`tls://` for Certificate authentication). Default port is `1883`.                                                                                                                                                                                                                                                                                                                     | `mqtt://broker.example.com:1883` |
| Reconnect period              | Time (in milliseconds) to wait before reconnection attempts                                                                                                                                                                                                                                                                                                                                                                                                                                               | `5000`                           |
| Connect timeout               | Maximum time (in milliseconds) to wait for connection establishment                                                                                                                                                                                                                                                                                                                                                                                                                                       | `30000`                          |
| Server certificate validation | **Standard**: the certificate of the broker is validated like a browser does, against the public certification authorities. **Trusted certificate**: it is validated against a certificate of the OIBus [certificate store](../engine/certificates.md#importing-a-trusted-certificate): a certification authority, against which the certificate and the host name are validated, or the certificate of the broker itself, which must match exactly. Only used with TLS (`mqtts://`, `tls://`, `wss://`). | Standard                         |
| Trusted certificate           | With **Trusted certificate** validation, the certificate OIBus trusts. Import an internal certification authority or a self-signed broker certificate from the selector, or trust the certificate the broker presents from the connection test.                                                                                                                                                                                                                                                           | `My CA`                          |

### Quality of Service {#quality-of-service}

| Setting        | Description                                                                                                                                            | Example Value    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- |
| QoS            | Quality of Service level: `0` (at most once), `1` (at least once, possible duplicates), `2` (exactly once).                                            | `0`, `1`, `2`    |
| **Persistent** | When enabled, the broker retains messages and queued deliveries across reconnections (requires QoS 1 or 2). When disabled, a clean session is started. | Enabled/Disabled |

### Authentication {#authentication}

#### No Authentication {#no-authentication}

| Setting | Description                               | Example Value |
| ------- | ----------------------------------------- | ------------- |
| (None)  | No authentication required for connection | -             |

| Setting  | Description                        | Example Value |

#### Certificate Authentication {#certificate-authentication}

| Setting        | Description                         | Example Value       |
| -------------- | ----------------------------------- | ------------------- |

### Data Throttling {#data-throttling}

| Setting                         | Description                                                                    | Example Value |
| ------------------------------- | ------------------------------------------------------------------------------ | ------------- |
| Number of messages before flush | Number of messages to accumulate before flushing to North caches               | `1000`        |
| Delay between flush             | Time delay (in milliseconds) between automatic flushes of accumulated messages | `1000`        |

## Item Settings {#item-settings}

Each item subscribes to one MQTT topic. MQTT uses a hierarchical topic structure with wildcard support:

| Setting   | Description                                          | Example Value            |
| --------- | ---------------------------------------------------- | ------------------------ |
| **Topic** | The MQTT topic to subscribe to. Wildcards supported. | `sensors/#`, `plant/+/T` |

### Topic Wildcards {#topic-wildcards}

| Setting | Description           | Example Value           |
| ------- | --------------------- | ----------------------- |
| `#`     | Multi-level wildcard  | `sensors/#`             |
| `+`     | Single-level wildcard | `sensors/+/temperature` |
