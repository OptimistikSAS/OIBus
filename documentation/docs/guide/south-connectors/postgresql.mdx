# PostgreSQL

Connect to and query PostgreSQL databases with OIBus.

:::info Compatibility Notes

- Supports PostgreSQL 9.6 and later

:::

## Specific Settings {#specific-settings}

| Setting            | Description                                                             | Example Value    |
| ------------------ | ----------------------------------------------------------------------- | ---------------- |
| Host               | IP address or hostname of the PostgreSQL server.                        | `192.168.1.10`   |
| Port               | Server port number. Default: `5432`.                                    | `5432`           |
| SSL                | Enable encrypted connection. Recommended for production.                | Enabled/Disabled |
| Database           | Name of the database to connect to.                                     | `production`     |
| Connection timeout | Maximum time in milliseconds to establish connection. Default: `10000`. | `10000`          |
| Request timeout    | Maximum execution time in milliseconds for individual SQL queries.      | `15000`          |
| Username           | Authentication username.                                                | `db_user`        |
| Password           | Authentication password.                                                | `••••••••`       |

:::tip Security Best Practices

- Use a read-only database user

:::

### Performance Considerations {#performance-considerations}

**Query Optimization**:

- Use indexed columns in WHERE clauses
- Limit result sets (avoid `SELECT *`)

**Resource Management**:

- SSL encryption adds minimal overhead
- Increase timeouts for large datasets or complex queries

## Exploring Tables {#exploring-tables}

Click **Explore** to browse the database's tables (with their column count and, where the database gives it, an
approximate row count) and the columns of each table, with their type and, where available, nullability, primary key
and default value. Check tables or columns and click
**Add in an item** to start an item whose query reads the checked columns (several tables are joined), tracked on a
date/time column picked automatically — see [SQL Tables in an Item](./common-settings.md#sql-tables-as-items) — or
**Metadata sync** to push the records of a table to OIAnalytics.

An [items synchronisation](./common-settings.md#items-synchronisation) on this connector runs a metadata query and
pushes its rows to OIAnalytics; it never creates items.

:::note PostgreSQL datetime field types
The following **Type** values are available for the tracking instant's datetime field:

| Type                    | Description                                       |
| ----------------------- | ------------------------------------------------- |
| String                  | String representation parsed with a custom format |
| Timestamp               | PostgreSQL `TIMESTAMP` column (no timezone)       |
| Timestamp with timezone | PostgreSQL `TIMESTAMPTZ` column (with timezone)   |
| ISO String              | ISO 8601 string (e.g. `2024-01-15T10:30:00.000Z`) |
| UNIX epoch (s)          | Unix timestamp in seconds                         |
| UNIX epoch (ms)         | Unix timestamp in milliseconds                    |

:::
