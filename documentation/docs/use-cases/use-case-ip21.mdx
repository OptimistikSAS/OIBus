# Aspen InfoPlus.21® (IP21) → Amazon S3™

## Beforehand {#beforehand}

AspenTech IP21 is a real-time data historian that collects, stores, and analyses time-series data from industrial processes. OIBus connects to IP21 via ODBC.

See the [North Amazon S3](../guide/north-connectors/aws-s3.md) and [South ODBC](../guide/south-connectors/odbc) connector pages for full configuration details.

This use case requires the **AspenTech SQLplus** ODBC driver on the OIBus machine. The example uses the following fictional network.

<div style={{ textAlign: 'center' }}>

![IP21 -> AWS S3](@site/static/img/use-cases/ip21-aws.svg)

</div>

:::caution Install OIBus close to IP21
The Aspen SQLplus driver is sensitive to network latency. Install OIBus on the IP21 server, or at least on the same local network. Additional network hops or firewalls between OIBus and the historian can cause data collection issues and performance degradation.
:::

## South ODBC {#south-odbc}

The ODBC connector uses the [node-odbc](https://github.com/markdirish/node-odbc) driver, which relies on the ODBC drivers installed on the OIBus machine. Install the **AspenTech SQLplus** ODBC driver on the machine running OIBus.

The connection string follows the standard ODBC format, for example `Driver={AspenTech SQLplus};HOST=192.169.0.2;PORT=10014;MAXROWS=12000000`.

### Items {#items}

The ODBC connector accepts SQL queries. See the [MSSQL item documentation](./use-case-mssql#sql-queries) for guidance on writing queries with `@StartTime` and `@EndTime` variables.

## North Amazon S3 {#north-amazon-s3}

You need the following before filling in the connector settings:

- Bucket: `oibus-test`
- Region: `eu-west-3`
- Folder: `north-local-oib` (leave empty to store files at the bucket root)
- Access key and secret key generated in Amazon S3
