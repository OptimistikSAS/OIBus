# OSIsoft PI System™ → OIAnalytics®

## Beforehand {#beforehand}

OSIsoft PI System™ is a real-time data management platform widely used in manufacturing, energy, and utilities to collect, store, and analyse time-series data from industrial processes.

See the [North OIAnalytics](../guide/north-connectors/oianalytics) and [South OSIsoft PI](../guide/south-connectors/osisoft-pi) connector pages for full configuration details.

This use case requires OIBus to run on a Windows x64 machine where PI AF Client is installed, either the PI server itself or another machine — see [PI AF Client configuration](../guide/south-connectors/osisoft-pi#pi-af-client-configuration) for details. ### Items {#items}

PI items can be of two types:

- **PI point** — retrieve time-series values for a single PI point.
- **PI query** — retrieve time-series values for all PI points matching a PI point query, such as `tag:=SINUS*`. The item name is used only for logging; the data is labelled with the actual PI point references.
