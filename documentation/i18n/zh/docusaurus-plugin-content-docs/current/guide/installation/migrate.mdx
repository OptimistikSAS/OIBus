## 迁移步骤 {#migration-steps}

1. 停止 OIBus 服务。
   :::tip
   您可以将数据文件夹压缩打包，或至少备份配置文件 `oibus.json` 及其 `keys` 目录。
   :::

2. 安装 [OIBus v3.9.6](#download-specific-version)。请务必指定**相同的数据文件夹**。通过登录
   `http://localhost:2223`（用户名 admin，密码 pass）检查 OIBus v3 是否正常运行。如果一切正常，继续下一步。

3. 停止 OIBus v3。

4. 将迁移工具复制到 OIBus **二进制文件夹**中。

5. 运行 OIBus 迁移工具。请务必指定正确的数据文件夹。

**Windows 命令**

```
oibus-upgrade.exe --config D:\OIBusData
```

**Linux / macOS 命令**

```
./oibus-upgrade --config /usr/oibus/OIBusData
```

6. 启动 OIBus v3。

:::tip
文件 `upgrade-journal.log` 包含迁移过程的日志。
:::

:::info 迁移的内容

- 引擎设置、IP 过滤器和 admin 用户（它会替换 OIBus v3 的默认 `admin` 用户）。
- South 连接器所使用的扫描模式。
- South 连接器及其点位。OPC UA®、OPC HDA、Modbus 和 ADS 连接器的点位会被归入分组，每个扫描模式一个分组。
  历史连接器的重叠时间会变为负的起始时间偏移。
- 历史 South 连接器最后完成的时刻，以及保留文件的文件夹扫描器已处理过的文件。
- North 连接器、它们的订阅，以及在其缓存、错误和归档文件夹中等待的数据。
  :::
