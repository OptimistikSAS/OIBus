# 导出/导入配置

OIBus 可以将其完整配置导出为一个可移植的 JSON 文件，并在之后将该文件导入 —— 无论是导入到同一实例还是不同实例 ——
以从头重建配置。这对于备份、灾难恢复或将配置克隆到新实例非常有用。

这两项操作都可以在 **引擎 > 设置** 中通过**导出配置**和**导入配置**按钮完成。

## 导出内容 {#what-gets-exported}

导出文件（`oibus-config-export.json`）是一个带版本号的信封文件，包含：

- 扫描模式
- IP 过滤器
- 证书
- 转换器
- 南向连接器（包括数据项和分组）
- 北向连接器
- 历史查询
- 用户
- OIAnalytics 注册设置（仅供参考 —— 详见下文的[注册](#registration-is-not-imported)）

引擎自身的设置（名称、端口、代理服务器、身份验证时长等）**不**包含在导出内容中，导入操作也不会改动这些设置。

### 密钥始终会被剥离 {#secrets-are-always-stripped}

任何密钥都不会被写入导出文件 —— 无论是明文还是加密形式。这适用于配置中所有类似密钥的字段：连接器凭证（密码、
API 密钥、令牌）、代理密码、Loki 日志记录密码、证书私钥以及用户密码。因此，导出的文件可以在不泄露任何凭证的情况下
共享或存储，但这也意味着这些字段在导入后必须手动重新输入 —— 详见[导入后的手动操作](#manual-steps-after-import)。

## 导入是完全替换，而非合并 {#import-is-a-full-replace-not-a-merge}

导入配置文件会**清除目标实例本地配置中所有相关部分，并根据文件重新创建**，同时保留每个实体原有的内部 ID。
此操作具有破坏性且无法撤销：实例上当前存在的每个南向连接器、北向连接器、历史查询、扫描模式、IP 过滤器、
转换器、证书和用户，都会在创建导入的内容之前被删除。UI 会要求明确确认（并重申这一点）后才能提交导入。

引擎自身的设置和 OIAnalytics 注册信息永远不会被导入操作清除或覆盖 —— 详见[注册](#registration-is-not-imported)。

如果上传的文件格式有误，或因以下任一原因被拒绝，**将不会写入任何内容**：导入操作是全有或全无的。

## 支持的版本 {#supported-versions}

每个导出文件都标注有 `formatVersion`（描述文件本身结构的整数）以及生成该文件的实例的 `oibusVersion`。

- **格式版本**：如果文件的 `formatVersion` 高于导入端 OIBus 构建所能读取的最高格式版本，导入将被直接拒绝。
  不存在下限 —— 较旧的格式版本始终会被接受处理。
- **OIBus 版本**：不存在最低受支持的 `oibusVersion`。在验证文件之前，OIBus 会查找所有针对晚于文件 `oibusVersion`
  的版本所注册的设置升级步骤，并应用匹配的步骤（按南向/北向连接器类型、历史查询方向或转换器）将较旧的设置结构
  升级为当前连接器清单所期望的形式。响应中会列出所应用的每一次升级。

在完成此类升级后，文件中的每个设置数据块都会根据当前的连接器清单进行验证。如果任何实体验证失败，整个导入操作
将被拒绝，并返回按实体列出的错误清单，同样不会写入任何内容。

## 导入后的手动操作 {#manual-steps-after-import}

由于密钥永远不会被导出，导入后的配置无法立即直接使用：

- **南向和北向连接器导入时会被设置为 `enabled: false`**，无论其导出时的值是什么。它们的设置会按导出内容原样导入，
  但所有类似密钥的字段均为空，因此如果保留启用状态，要么会因凭证为空而连接失败，要么（对于可写协议）会在没有
  有意义设置的情况下进行连接。必须手动重新输入凭证，并重新启用每个连接器，才能使其再次运行。
- **证书导入时不包含其私钥。** 证书条目本身（名称、公钥、证书、证书链、到期时间）会以其原始 ID 重新创建，
  因此任何引用它的内容都能继续正常解析，但必须手动重新导入私钥，证书才能用于 TLS。
- **用户会以随机密码重新创建**，因为密码永远不会被导出。每个导入的用户都必须重置密码才能再次登录。
- **标准转换器通过函数名匹配**，而非重新创建 —— 它们在 OIBus 启动时被预置一次，并根据其 `functionName` 与导入的
  配置进行匹配。如果目标实例没有函数名匹配的标准转换器（例如，OIBus 构建版本较旧或较新），对它的链接将被跳过
  并报告为警告。自定义转换器则始终以其原始 ID 重新创建。

导入响应（以及相应的 UI 面板）会列出导入过程中应用的每一次升级和产生的每一条警告 —— 包括上述内容 —— 因此这些
信息在导入完成后仍会保持可见，而不是显示在一闪即逝的提示中。

### 注册信息不会被导入 {#registration-is-not-imported}

OIAnalytics 注册设置包含在导出文件中，仅供参考。导入文件永远不会写入注册状态 —— 必须手动完成目标实例向
OIAnalytics 的注册（或重新注册），方式与在全新实例上相同。
