# 引擎设置

## OIBus 名称 {#oibus-name}

为您的 OIBus 实例命名很重要,尤其是在管理多个实例时。清晰的名称有助于在日志、仪表板和监控工具中识别每个 OIBus。

## Web 服务器 {#web-server}

### 端口 {#port}

通过 Web 界面访问 OIBus 设置的默认端口是 **2223**(`http://localhost:2223`)。
如有需要,您可以更改此端口 —— 例如,为了解决冲突或提高安全性。

### 身份验证时长 {#authentication-duration}

**身份验证时长**设置控制登录会话在用户必须重新登录之前保持有效的时长。可选值为 **1 小时**、**6 小时**、
**1 天**、**3 天**、**7 天**(默认)、**14 天**和 **30 天**。

## 代理服务器 {#proxy-server}

OIBus 可以充当**代理服务器**,将 HTTP(S) 请求转发到目标主机。当两个 OIBus 实例部署在不同网络中时,此功能特别有用:

- **OIBus1**:安装在可访问互联网的网络中。
- **OIBus2**:安装在无法访问互联网的网络中。

通过将 **OIBus1** 配置为代理服务器,**OIBus2** 可以通过 **OIBus1** 将数据发送到互联网,前提是北向连接器允许这样做。

### 前提条件 {#prerequisites}

1. **防火墙配置**:确保您的防火墙允许 **OIBus2** 到 **OIBus1** 的指定代理端口的入站连接。
2. **IP 过滤器**:在 **OIBus1** 的 [IP 过滤器](./ip-filters.mdx) 部分中授权 **OIBus2** 的 IP 地址。

### 配置步骤 {#configuration-steps}

#### 在 OIBus1(代理服务器)上 {#on-oibus1-proxy-server}

1. 启用**代理服务器**选项。
2. 设置**监听端口**(例如 `2224`)。
3. 可选地设置**用户名**和**密码**,要求客户端在使用代理之前进行身份验证(见下文的[身份验证](#authentication))。
4. 确保防火墙允许该端口的入站连接。
5. 在 **IP 过滤器**部分中授权 **OIBus2** 的 IP 地址。

#### 在 OIBus2(代理客户端)上 {#on-oibus2-proxy-client}

1. 配置**北向连接器**或 **OIAnalytics 注册设置**以使用代理服务器。
2. 指定 **OIBus1** 代理服务器的地址和端口(例如 `http://oibus1.fr:2224`)。
3. 如果 **OIBus1** 的代理服务器需要身份验证,请在北向连接器或注册的代理设置中提供相同的**用户名**和**密码**。

### 身份验证 {#authentication}

代理服务器可以要求客户端在转发任何请求之前使用**用户名**和**密码**(HTTP 基本身份验证)进行身份验证。留空这些字段
即可允许匿名访问。

:::tip
IP 过滤会在身份验证之前检查:来自未授权主机的请求会在其凭证被检查之前就被拒绝。两者可以结合使用以实现纵深防御:
IP 过滤器限制哪些主机可以访问代理,而身份验证则控制这些主机中谁可以使用它。
:::

### 转发到上游代理 {#forward-to-an-upstream-proxy}

如果 **OIBus1** 本身没有直接访问互联网的权限(例如,必须通过企业代理),可以将其配置为将收到的每个请求转发到
**上游代理**,而不是直接联系目标主机:

```
OIBus2 → OIBus1(代理服务器) → 上游代理 → 互联网
```

要配置此项,请在 **OIBus1** 的代理服务器设置中启用**转发到上游代理**,并提供:

- **URL**:上游代理的地址(例如 `http://corporate-proxy.company.com:8080`)。
- **用户名** / **密码**:上游代理所需的凭证(如果需要身份验证)。

这与上文的[身份验证](#authentication)设置是相互独立的:上游凭证由 **OIBus1** 用于访问上游代理,而代理服务器自身
的用户名/密码(如已设置)仍然控制哪些客户端(例如 **OIBus2**)可以将 **OIBus1** 用作代理。

### 示例 {#example}

#### 场景 {#scenario}

- **OIBus1**:
- 充当代理服务器。
- 监听端口 `2224`。
- 可通过 `http://oibus1.fr` 访问。
- **OIBus2**:
- 配置了一个 [Azure Blob 北向连接器](../north-connectors/azure-blob.md)和一个
  [OIAnalytics 北向连接器](../north-connectors/oianalytics.md)。
- 通过 **OIBus1** 的代理服务器将数据发送到 Azure 和 OIAnalytics。

<div style={{ textAlign: 'center' }}>![网络代理示例](../../../static/img/guide/engine/proxy-network.svg)</div>

#### 配置 {#configuration}

1. **在 OIBus1 上**:

- 启用代理服务器,并将其设置为监听端口 `2224`。
- 在 **IP 过滤器**中授权 **OIBus2** 的 IP 地址。

<div style={{ textAlign: 'center' }}>![代理服务器示例](../../../static/img/guide/engine/proxy-server-example.png)</div>

2. **在 OIBus2 上**:

- 在 **Azure Blob 北向连接器**设置中,指定代理服务器:
- **代理 URL**:`http://oibus1.fr:2224`

<div style={{ textAlign: 'center' }}>![北向代理示例](../../../static/img/guide/engine/north-proxy-example.png)</div>

:::tip
如果您在使用 [北向 OIAnalytics](../north-connectors/oianalytics.md) 及 [OIAnalytics 注册](../installation/oianalytics.mdx),
请在**注册设置**中配置代理客户端设置。
:::

## 日志参数 {#logging-parameters}

OIBus 支持六种日志级别,从最关键到最不关键依次为:

| 日志级别 | 描述                                                                        |
| -------- | --------------------------------------------------------------------------- |
| Silent   | 停用所有日志。                                                             |
| Error    | 仅记录错误。                                                               |
| Warning  | 记录警告和错误。                                                           |
| Info     | 记录信息性消息、警告和错误。                                               |
| Debug    | 记录用于调试的详细信息,以及以上所有级别的内容。                           |
| Trace    | 记录高度详细和冗长的信息,主要用于故障排查。                               |

:::caution
仅在故障排查时使用 **Trace** 和 **Debug** 日志级别,因为它们会产生大量数据。
:::

### 日志输出选项 {#log-output-options}

#### OIAnalytics {#oianalytics}

- 如果 OIBus 已[注册到 OIAnalytics](../installation/oianalytics.mdx),日志可以转发到 OIAnalytics。
- 如果 OIBus 未注册,这些设置将被忽略。

#### 数据库 {#database}

- 将日志保存在本地 **SQLite 数据库**中。
- 在 OIBus 的**日志选项卡**中查看日志。
- 设置**最大日志数量**,以防止数据库过大。较旧的日志会被自动清除。

#### 文件 {#file}

- 将日志存储在一个或多个文件中。
- 配置:
- **最大文件大小**(以 MB 为单位)
- **文件数量**,用于日志轮转

#### Loki {#loki}

- 批量将日志发送到远程 **Loki** 实例。
- 配置:
- **URL**
- **批处理间隔**(默认:60 秒)
- **基本身份验证凭证**(用户名和密码)

:::caution
发送到 Loki 的日志通过 **OIBus ID** 和名称进行标识。请确保正确设置名称以便定位您的日志,尤其是在您有多个 OIBus
实例的情况下。
:::

#### Syslog {#syslog}

- 将日志发送到远程 **Syslog** 服务器(RFC 5424)。
- 配置:
- **主机**
- **端口**(默认:514)
- **协议**:UDP 或 TCP

#### 控制台 {#console}

- 在**控制台**中显示日志。
- 通过从终端运行 OIBus 来访问。
