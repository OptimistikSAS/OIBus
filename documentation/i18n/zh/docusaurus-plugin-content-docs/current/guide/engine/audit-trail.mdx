# 审计追踪

每当创建、更新或删除某个配置实体时，OIBus 都会记录一条审计日志条目，因此您可以查看谁在何时更改
了什么内容。

## 被审计的内容 {#what-gets-audited}

每条审计日志条目都会记录：

| 字段                 | 说明                                                                          |
| -------------------- | ----------------------------------------------------------------------------- |
| **Entity type / ID** | 发生更改的实体类型及其标识符。                                                |
| **Action**           | `Create`、`Update` 或 `Delete`。                                              |
| **User**             | 执行更改的用户。                                                              |
| **Date**             | 记录更改的时间。                                                              |
| **Before / After**   | 更改前后该实体的 JSON 快照——`Create` 时 before 为空，`Delete` 时 after 为空。 |

以下实体类型会被审计：South 连接器、South 项目、South 项目分组、North 连接器、North 转换器、
历史查询、历史查询项目、历史查询转换器、扫描模式、IP 过滤器、证书、用户、转换器、引擎，以及
OIAnalytics 注册。

## 查看审计追踪 {#viewing-the-audit-trail}

### 审计页面 {#the-audit-page}

打开账户菜单（右上角）并选择**审计（Audit）**，即可查看整个 OIBus 实例中的每一条审计日志条目。
可按**实体类型**、**操作**以及**开始/结束**日期范围进行筛选，然后点击任意行上的 🔍 图标以打开
该条目的完整历史记录。

### 从实体自身的列表中查看 {#from-an-entitys-own-list}

大多数配置列表页面——South、North、历史查询、扫描模式、IP 过滤器、证书和转换器——每一行也都有
一个审计图标，可以直接打开该实体自身的历史记录，而无需通过全局审计页面。

## 查看历史记录条目 {#reading-a-history-entry}

历史记录视图会列出为该实体记录的每一次更改，按最新优先排序。展开某一行以查看具体的更改内容，
共有三种模式（可通过顶部的下拉菜单在它们之间切换）：

| 模式                  | 说明                                                                         |
| --------------------- | ---------------------------------------------------------------------------- |
| **Table**（默认）     | 每个字段一行，显示其**更改前**和**更改后**的值。发生变化的字段会被高亮显示。 |
| **JSON diff**         | 两个 JSON 快照的统一差异视图。                                               |
| **JSON side by side** | 并排显示两个 JSON 快照。                                                     |

## 保留期 {#retention}

审计日志条目会保留可配置的天数，之后会被自动清除——请参阅
[日志参数](./engine-settings.mdx#logging-parameters)下的**审计日志保留**。
