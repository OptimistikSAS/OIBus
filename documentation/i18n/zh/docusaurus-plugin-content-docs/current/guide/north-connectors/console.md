# 控制台

**控制台北向连接器**直接在控制台输出中显示文件名或值，非常适合用于**调试和开发**。

## 特定设置 {#specific-settings}

| 设置       | 描述                                                                             | 示例值   |
| ---------- | ------------------------------------------------------------------------------------ | ---------- |
| **详细模式** | 启用时，以**详细表格**显示接收到的数据。禁用时，仅显示接收到的**值的数量**。       | 启用/禁用 |

## 在生产环境中使用控制台 {#using-the-console-in-production}

在 OIBus 作为服务运行的生产环境（Windows/Linux）中，请按照以下步骤查看控制台输出：

1. 使用您操作系统的服务管理器**停止 OIBus 服务**。
2. 以管理员权限从终端**手动启动 OIBus**：
   - **Windows**：导航到安装文件夹并执行 `go.bat`。
   - **Linux**：导航到安装文件夹并运行 `go.sh`。
3. 直接在终端中查看控制台输出。

:::caution 重要
调试结束后，请记得：

1. 退出终端会话。
2. 使用您操作系统的服务管理器**重新启动 OIBus 服务**以恢复正常运行。

:::

## 最佳实践 {#best-practices}

- 在开发或故障排查期间使用**详细模式**来检查数据结构和内容。
- 不要在生产环境中使用，以减少控制台的杂乱信息。
- 对于需要持久化的数据，建议使用[文件写入北向连接器](../north-connectors/file-writer.md)，而不是仅依赖控制台输出。
