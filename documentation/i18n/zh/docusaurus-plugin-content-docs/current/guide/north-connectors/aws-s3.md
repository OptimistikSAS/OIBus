# Amazon S3™

**Amazon S3™ 北向连接器**允许您将文件存储到 **Amazon S3™（Simple Storage Service）**中。它非常适合长期存储、数据湖或与
AWS 服务集成的场景。

**示例用例**：

- **数据湖集成**：存储历史数据以用于分析或合规。
- **备份与归档**：将 OIBus 的数据安全归档到 Amazon S3。
- **AWS 生态系统集成**：将存储的数据用于 Athena、Redshift 或 Glue 等 AWS 服务。

## 特定设置 {#specific-settings}

配置以下参数以连接到您的 Amazon S3 存储桶：

| 设置       | 描述                                     | 示例值                    |
| ---------- | ---------------------------------------- | -------------------------- |
| **存储桶** | 用于存储文件的 Amazon S3 存储桶名称。     | `my-oibus-bucket`          |
| **区域**   | 存储桶所在的 AWS 区域。                   | `eu-west-3`                |
| **文件夹** | 存储桶内用于存储文件的特定文件夹。         | `oibus/data`                |
| **访问密钥** | 用于连接 Amazon S3 存储桶的身份验证密钥。 | `AKIAIOSFODNN7EXAMPLE`     |
| **秘密密钥** | 与访问密钥关联的秘密密钥。               | `••••••••`                 |

### 代理配置 {#proxy-configuration}

如果您的网络基础设施要求请求通过代理服务器才能到达 Amazon S3，请启用**使用代理**选项并在下方配置代理详细信息。

| 设置           | 描述                             | 示例值                             |
| -------------- | -------------------------------- | ----------------------------------- |
| **使用代理**   | 通过代理服务器路由请求。         | 启用/禁用                           |
| **代理 URL**   | 代理服务器的 URL。               | `http://proxy.example.com:8080`     |
| **代理用户名** | 用于代理身份验证的用户名（如需要）。 | `proxy_user`                      |
| **代理密码**   | 用于代理身份验证的密码（如需要）。 | `••••••••`                        |

## 最佳实践 {#best-practices}

- **IAM 权限**：确保提供的访问密钥和秘密密钥具有必要的权限（例如 `s3:PutObject`）。
- **监控**：在 AWS S3 控制台中监控存储使用情况和成本。
