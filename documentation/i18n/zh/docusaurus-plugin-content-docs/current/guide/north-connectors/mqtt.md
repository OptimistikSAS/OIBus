# MQTT

**MQTT 北向连接器**使 OIBus 能够**向 MQTT Broker发布数据**，从而实现与物联网平台、消息队列以及兼容 MQTT 的系统的无缝
集成。

**示例用例**

- **物联网平台集成**：向云端物联网平台发布传感器数据
- **实时通知**：向订阅系统发送警报和事件
- **边缘设备控制**：通过 MQTT 主题向边缘设备发送命令

## 特定设置 {#specific-settings}

### 连接配置 {#connection-configuration}

| 设置               | 描述                                                                                                      | 示例值                           |
| ------------------ | --------------------------------------------------------------------------------------------------------- | -------------------------------- |
| **URL**            | MQTT Broker的 URL。                                                                                       | `mqtt://broker.example.com:1883` |
| **QoS**            | 服务质量等级：`0`（最多一次）、`1`（至少一次）、`2`（恰好一次）。                                         | `0`、`1`、`2`                    |
| **拒绝未授权连接** | 拒绝无法被授权的连接。                                                                                    | 已启用/已禁用                    |
| **重连周期**       | 重新连接尝试之间的时间间隔（毫秒）。                                                                      | `5000`                           |
| **连接超时**       | 等待连接的最长时间（毫秒）。                                                                              | `30000`                          |
| **持久化**         | 启用以支持在 Broker 重启后仍然存续的持久会话。仅在 **QoS** 为 `1` 或 `2` 时可用——QoS `0` 会话无法持久化。 | 已启用/已禁用                    |

### 身份验证 {#authentication}

| 设置             | 描述                                                                                | 示例值                      |
| ---------------- | ----------------------------------------------------------------------------------- | --------------------------- |
| **认证**         | 身份验证方法。                                                                      | `无`、`用户名/密码`、`证书` |
| **用户名**       | 用于 Broker 身份验证的用户名。用户名/密码方式必填。                                 | `mqtt_user`                 |
| **密码**         | 用于 Broker 身份验证的密码。与用户名/密码方式一起使用（编辑时留空以保留现有密码）。 | `••••••••`                  |
| **证书文件路径** | 已签名证书文件的路径。证书身份验证方式必填。                                        | `/path/to/cert.pem`         |
| **密钥文件路径** | 私钥文件的路径。证书身份验证方式必填。                                              | `/path/to/key.pem`          |
| **CA 文件路径**  | 证书颁发机构文件的路径。证书身份验证方式必填。                                      | `/path/to/ca.pem`           |
