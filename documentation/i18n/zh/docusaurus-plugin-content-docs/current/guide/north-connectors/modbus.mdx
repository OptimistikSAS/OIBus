# Modbus

**Modbus 北向连接器**使 OIBus 能够**将数据写入兼容 Modbus 的设备**，从而实现与 PLC、RTU 以及其他支持 Modbus 协议的
工业设备的无缝集成。

**示例用例**

- **过程控制**：将设定值和控制值写入 PLC
- **配置管理**：远程更新设备参数
- **系统集成**：将 OIBus 数据与兼容 Modbus 的设备连接起来

## 特定设置 {#specific-settings}

### 连接配置 {#connection-configuration}

| 设置             | 描述                                                                                         | 示例值           |
| ---------------- | -------------------------------------------------------------------------------------------------- | ------------------ |
| **主机**         | Modbus 服务器机器的 IP 地址或主机名。                                                             | `192.168.1.100`    |
| **端口**         | 用于连接的端口（默认为 502）。                                                                     | `502`              |
| **连接超时**     | 等待连接的最长时间（毫秒）。                                                                       | `10000`            |
| **重试间隔**     | 重新连接前等待的时间（毫秒），无论是连接失败后还是写入命令失败后。                                 | `10000`            |
| **从站 ID**      | 标识 Modbus 源设备（默认为 1）。                                                                   | `1`                |
| **地址偏移**     | 大多数 PLC 没有偏移（Modbus 选项）。部分 PLC 的地址范围可能从 1 而非 0 开始（JBus 选项）           | `Modbus`           |

### 数据格式选项 {#data-format-options}

| 设置             | 描述                                     | 示例值       |
| ---------------- | ------------------------------------------- | -------------- |
| **字节序**       | 位编码类型。                                 | `Big endian`  |
| **交换字节**     | 是否交换 16 位字内的字节。                   | 启用/禁用     |
| **交换字**       | 是否在 32 位组内交换 16 位字。               | 启用/禁用     |

:::caution 字节序和交换设置目前对写入没有影响
此连接器仅写入单个 16 位寄存器或线圈（`writeSingleCoil` / `writeSingleRegister`）——它没有多寄存器写入路径，因此
**字节序**、**交换字节**和**交换字**目前在发送数据时不会生效。更改这些设置不会对实际写入的内容产生任何影响。上方的
测试工具仅用于演示字节布局的概念（与 Modbus 南向连接器共用，在读取数据时这些设置_确实_会生效），并不代表此连接器
的实际行为。
:::
