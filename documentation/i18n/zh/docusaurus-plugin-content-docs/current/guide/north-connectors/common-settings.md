# 通用设置

**北向连接器**将数据从 OIBus 发送到目标应用程序。本页说明如何配置和管理北向连接器。

## 添加北向连接器 {#adding-a-north-connector}

1. 导航到**北向**页面。
2. 点击 **+** 按钮。
3. 选择连接器类型并配置其设置。
4. 从连接器的显示页面监控或调整设置。

## 常规设置 {#general-settings}

| 设置     | 描述                                         | 示例值              |
| -------- | -------------------------------------------- | ------------------- |
| **名称** | 用于标识连接器用途的用户友好标签。           | `My MQTT Connector` |
| **描述** | 关于连接、访问权限或独特特征的可选详细信息。 | `Production broker` |
| **状态** | 启用或禁用连接器（从列表或其显示页面）。     | 已启用/已禁用       |

:::caution 已禁用的北向连接器
已禁用的北向连接器**不会缓存任何数据**。
:::

## 特定部分 {#specific-section}

有关特定类型的设置，请参阅各连接器的文档。

### 测试连接 {#testing-connection}

使用**测试设置**按钮验证您的连接配置。

## 缓存设置 {#cache-settings}

### 触发条件 {#trigger-conditions}

配置数据发送到目标应用程序的时机：

| 设置         | 描述                                                                   | 示例值     |
| ------------ | ---------------------------------------------------------------------- | ---------- |
| **计划**     | 定义数据传输的频率。使用[扫描模式](../engine/scan-modes.mdx)进行配置。 | `每 10 秒` |
| **元素数量** | （记录列表）当达到指定数量的元素时发送数据，忽略计划。`0` 禁用此触发。 | `1000`     |
| **文件数量** | （文件）当达到指定数量的文件时发送数据，忽略计划。`0` 禁用此触发。     | `10`       |

### 限流 {#throttling}

控制数据传输以避免目标或网络过载：

| 设置                       | 描述                                                                               | 示例值  |
| -------------------------- | ---------------------------------------------------------------------------------- | ------- |
| **两次发送之间的最小延迟** | 两次传输之间等待的时间（毫秒）。                                                   | `1000`  |
| **最大元素数量**           | 单次传输中发送的最大元素数量。                                                     | `10000` |
| **最大存储大小**           | 缓存 + 错误 + 归档的最大大小（MB）。达到限制后多余的数据将被丢弃。`0` 表示不限制。 | `1000`  |

### 错误 {#errors}

管理 OIBus 如何处理传输失败：

| 设置                       | 描述                                                    | 示例值 |
| -------------------------- | ------------------------------------------------------- | ------ |
| **出错后重试前的等待延迟** | 失败后重试前等待的时间（毫秒）。                        | `5000` |
| **重试次数**               | 将失败数据移入错误文件夹之前的重试次数。                | `3`    |
| **错误数据的保留时长**     | 错误数据保留的时长（小时）。设置为 `0` 表示无限期保留。 | `72`   |

:::tip 可重试发送
某些北向连接器，例如 [OIAnalytics 北向连接器](./oianalytics.md)，会针对特定错误**无限期重试**发送数据，即使已超过重试
次数。这涵盖网络故障以及某些预计会随着底层问题（例如配置错误的 API 密钥、临时性中断）修复而解决的 HTTP 错误响应
（例如身份验证或速率限制错误），而不会将数据移动到错误文件夹。
:::

### 归档 {#archive}

启用归档以保留已传输的数据：

| 设置                   | 描述                                                    | 示例值        |
| ---------------------- | ------------------------------------------------------- | ------------- |
| **已启用**             | 切换以启用或禁用归档。                                  | 已启用/已禁用 |
| **归档数据的保留时长** | 归档数据保留的时长（小时）。设置为 `0` 表示无限期保留。 | `168`         |

:::caution 磁盘空间
如果文件被无限期保留，请定期手动清理归档文件夹，以避免过度占用磁盘空间。
:::

## 转换器 {#transformers}

转换器在**数据被缓存之前**运行——它们处理来自南向连接器的传入数据，并决定实际进入北向连接器缓存的内容。您可以为北向
连接器应用一个或多个转换器，以：

- **过滤数据**：根据其来源包含或排除特定数据点。
- **修改数据**：更改值、重命名字段或重新构建数据。
- **丰富数据**：添加额外的上下文或元数据。
- **转换格式**：在不同格式之间转换数据（例如，JSON 转 CSV）。

每个转换器都与一个**来源**（南向连接器、OIBus API 或 OIAnalytics 设定值）相关联，对于南向连接器，还与其适用的数据项
相关联。添加转换器时，您需要先选择来源，然后为该北向连接器类型选择兼容的转换器。参见
[配置转换器](../engine/transformers.mdx#configuring-a-transformer)。

:::info 标准转换器
标准转换器是预先构建好的，根据来源和北向连接器类型提供。这些转换器涵盖常见用例，可直接在 UI 中配置。
:::

:::tip 自定义转换器
对于高级用例，您可以创建自定义转换器：

- 前往[引擎转换器部分](../engine/transformers.mdx)。
- 使用您自己的代码创建新的转换器。
- 为转换器定义可配置的选项。

您的自定义转换器随后将可在北向连接器设置中选择使用。

:::

## 数据过滤 {#data-filtering}

转换器同时也是用于过滤北向连接器所接收数据的机制：北向连接器只缓存配置了转换器的来源（及数据项）的数据。
**没有转换器的数据会被忽略。**

要按原样发送数据，请使用直通转换器：文件和 JSON 有效载荷使用
[文件（原样、重命名或转换）](../engine/transformers.mdx#file-as-is-renamed-or-converted)，记录列表（包括 OIAnalytics
设定值）使用[文件](../engine/transformers.mdx#file-from-records)。

:::info 升级到 3.10
在 3.10 之前，与北向连接器类型兼容的数据无需转换器即会被缓存，而**不转换**和**忽略**转换器用于强制或阻止缓存。升级时，
OIBus 会添加直通转换器，以重现每个北向连接器原先接收的数据（在南向连接器级别添加，以便新的数据项仍会被发送），用它们
替换**不转换**，并将设置为**忽略**的数据项从其原本继承的转换器中排除（**排除部分数据项**；对于历史查询，这些转换器会
缩小为其他数据项的列表）。OIBus API 的文件会经过一个适用于所有数据源的**文件（原样、重命名或转换）**转换器。
:::
