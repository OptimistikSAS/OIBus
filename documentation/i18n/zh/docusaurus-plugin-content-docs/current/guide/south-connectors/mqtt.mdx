# MQTT

MQTT（消息队列遥测传输）是一种轻量级协议，专为使用发布/订阅模型的实时消息传递而设计。OIBus 作为
MQTT 客户端，使用 [MQTT.js](https://github.com/mqttjs/MQTT.js) 库与
MQTT 代理进行交互。

## 特定设置 {#specific-settings}

### 连接 {#connection}

| 设置             | 描述                                                                                                                                                                           | 示例值                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| URL                 | MQTT 代理的地址。接受 `mqtt://`、`mqtts://`、`tcp://`、`tls://`、`ws://` 或 `wss://`（证书认证请使用 `mqtts://`/`tls://`）。默认端口为 `1883`。 | `mqtt://broker.example.com:1883` |
| Reconnect period    | 重连尝试前等待的时间（毫秒）                                                                                                                           | `5000`                           |
| Connect timeout     | 等待连接建立的最长时间（毫秒）                                                                                                                   | `30000`                          |
| Reject unauthorized | 拒绝使用未验证证书（例如自签名证书）的连接                                                                                                                                   | 启用/禁用                 |

### 服务质量 {#quality-of-service}

| 设置        | 描述                                                                                                                                            | 示例值    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------- |
| QoS            | 服务质量等级：`0`（最多一次）、`1`（至少一次，可能重复）、`2`（恰好一次）。                                            | `0`, `1`, `2`    |
| **Persistent** | 启用后，代理会在重新连接期间保留消息和排队的投递（需要 QoS 1 或 2）。禁用时，将启动一个干净会话。 | 启用/禁用 |

### 认证 {#authentication}

#### 无认证 {#no-authentication}

| 设置 | 描述                               | 示例值 |
| ------- | ----------------------------------------- | ------------- |
| （无）  | 连接不需要认证 | -             |

#### 用户名/密码 {#username--password}

| 设置  | 描述                        | 示例值 |
| -------- | ----------------------------------- | ------------- |
| Username | 用于代理认证的用户名 | `mqtt_user`   |
| Password | 用于代理认证的密码 | `••••••••`    |

#### 证书认证 {#certificate-authentication}

| 设置        | 描述                                                                      | 示例值       |
| -------------- | -------------------------------------------------------------------------------- | ------------------- |
| Cert file path | 已签名证书文件的路径                                              | `/path/to/cert.pem` |
| Key file path  | 私钥文件的路径                                                     | `/path/to/key.pem`  |
| CA file path   | 证书颁发机构文件的路径。证书认证时必填。 | `/path/to/ca.pem`   |

### 数据节流 {#data-throttling}

| 设置                         | 描述                                                                    | 示例值 |
| -------------------------------- | ------------------------------------------------------------------------------ | ------------- |
| Number of messages before flush | 刷新到北向缓存之前累积的消息数量               | `1000`        |
| Delay between flush             | 自动刷新累积消息之间的时间延迟（毫秒） | `1000`        |

## 条目设置 {#item-settings}

每个条目订阅一个 MQTT 主题。MQTT 使用支持通配符的分层主题结构：

| 设置   | 描述                                          | 示例值            |
| --------- | ---------------------------------------------------- | ------------------------ |
| **Topic** | 要订阅的 MQTT 主题。支持通配符。 | `sensors/#`, `plant/+/T` |

### 主题通配符 {#topic-wildcards}

| 设置 | 描述           | 示例值           |
| ------- | --------------------- | ----------------------- |
| `#`     | 多级通配符  | `sensors/#`             |
| `+`     | 单级通配符 | `sensors/+/temperature` |
