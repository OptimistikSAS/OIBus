# Microsoft SQL Server™

使用 OIBus 连接并查询 Microsoft SQL Server™（MSSQL）数据库。

该连接器通常用于从将数据存储在 SQL Server 中的工业平台提取过程数据和历史数据，例如 **AVEVA™ Historian**（前身为 Wonderware® InSQL）或 **Inductive Automation Ignition®**。

:::info 兼容性说明

- 支持 SQL Server 2012 及更高版本
- 要求在 SQL Server 上启用 TCP/IP 协议

:::

## 特定设置 {#specific-settings}

| 设置           | 描述                                                                  | 示例值         |
| -------------- | --------------------------------------------------------------------- | -------------- |
| 主机           | SQL Server 实例的 IP 地址或主机名。                                   | `192.168.1.10` |
| 端口           | SQL Server 端口号。默认值：`1433`。                                   | `1433`         |
| 连接超时       | 建立连接的最长时间（毫秒）。默认值：`5000`。                          | `5000`         |
| 数据库         | 要连接的数据库名称。                                                  | `production`   |
| 使用加密       | 在 OIBus 与数据库之间启用数据加密。                                   | 启用/禁用      |
| 信任服务器证书 | 接受自签名或已过期的证书。请谨慎使用。                                | 启用/禁用      |
| 用户名         | 认证用户名。                                                          | `sa`           |
| 密码           | 认证密码。                                                            | `••••••••`     |
| 域             | 用于域认证的 Active Directory 域（可选）。                            | `CORP`         |
| 空闲连接超时   | 连接池中未使用的连接在关闭前保持打开的时间（毫秒）。默认值：`30000`。 | `30000`        |
| 最大并行查询数 | 同时查询的项目或分组的最大数量，从 `1`（串行）到 `8`。默认值：`1`。   | `2`            |

:::note 并行查询
OIBus 维护一个最多包含该数量数据库连接的连接池，连接在查询需要时打开，并在空闲连接超时后关闭：每个连接都会增加数据源的负载。请将该值保持在 SQL Server 登录名可用的连接数以下。
:::

### 安全最佳实践 {#security-best-practices}

- **用户权限**：始终使用只读数据库用户
- **证书验证**：仅在开发/测试环境中信任服务器证书
- **加密**：对敏感数据、不受信任的网络或合规性要求启用加密

### 性能考量 {#performance-considerations}

**查询优化**：

- 在 WHERE 子句中使用带索引的列
- 限制结果集（避免使用 `SELECT *`）
- 优先使用参数化查询

**资源管理**：

- 加密会增加 CPU 开销
- 为长时间运行的查询增加超时时间
- 为大型结果集实现分页
- 尽可能复用连接

## 浏览数据表 {#exploring-tables}

点击 **浏览** 可浏览数据库的表（附带列数，以及在数据库提供时的近似行数）和每个表的列，包括列的类型，以及在可获取时的
是否可为空、主键和默认值。勾选表或列后点击 **添加为项**，即可为每个表创建一个项目，其查询读取所勾选的列，并基于自动
选取的日期/时间列进行跟踪——参见 [SQL 表作为项目](./common-settings.md#sql-tables-as-items)。

此连接器上的[项同步](./common-settings.md#items-synchronisation)会运行一个元数据查询并将其结果行推送到 OIAnalytics；
它从不创建项目。

<ItemSettings />

:::note MSSQL 项目请求超时
每个 MSSQL 项目都有自己的**请求超时**字段（毫秒），用于设置该项目查询的最长执行时间。**连接超时**仅限定 OIBus
等待建立连接的时间，项目之外运行的查询（连接测试、浏览、发现）在 15 秒后超时。
:::

:::note MSSQL 日期时间字段类型
以下**类型**值可用于 Microsoft SQL Server 中跟踪的时刻的日期时间字段：

| 类型              | 描述                                               |
| ----------------- | -------------------------------------------------- |
| 字符串            | 使用自定义格式解析的字符串表示形式                 |
| 日期              | SQL `DATE` 列（仅日期，无时间）                    |
| DateTime          | SQL `DATETIME` 列                                  |
| DateTime2         | SQL `DATETIME2` 列（更高精度）                     |
| DateTime Offset   | SQL `DATETIMEOFFSET` 列（包含时区偏移量）          |
| Small DateTime    | SQL `SMALLDATETIME` 列（分钟精度）                 |
| ISO 字符串        | ISO 8601 字符串（例如 `2024-01-15T10:30:00.000Z`） |
| UNIX 纪元（秒）   | 以秒为单位的 Unix 时间戳                           |
| UNIX 纪元（毫秒） | 以毫秒为单位的 Unix 时间戳                         |

:::
