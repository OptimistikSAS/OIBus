# ODBC

通过安装在 OIBus 机器上的 ODBC 驱动程序连接到 ODBC 数据源。对于 Aspen InfoPlus.21®（IP21）等系统以及其他兼容 ODBC 的应用程序特别有用。

:::info 兼容性说明

- 适用于任何兼容 ODBC 的数据源
- 推荐用于 Aspen IP21 连接
- 需要在 OIBus 机器上安装数据源的 ODBC 驱动程序

:::

## 特定设置 {#specific-settings}

| 设置           | 描述                                                                                                                                                       | 示例值                                            |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 连接超时       | 建立连接的最长时间（毫秒）。默认值：`15000`。                                                                                                              | `15000`                                           |
| 连接字符串     | 驱动程序特定格式的 ODBC 连接字符串。                                                                                                                       | `Driver={AspenTech SQLplus};HOST=ip21;PORT=10014` |
| 密码           | 认证密码（安全存储）。始终以 `PWD=<password>;` 的形式附加 —— 如果您的连接字符串已经包含自己的 `PWD=`/`Pwd=` 条目，请将其从此处或字符串中移除，以避免重复。 | `••••••••`                                        |
| 最大并行查询数 | 同时查询的项目或分组的最大数量，从 `1`（串行）到 `8`。默认值：`1`。                                                                                        | `2`                                               |

:::note 并行查询
每个并行运行的查询都会打开自己的数据库连接，并增加数据源的负载。ODBC 驱动调用在 Node.js 线程池上运行（默认 4 个线程，与文件访问共享）：大于 `4` 的值不会加快查询。
:::

### 连接字符串示例 {#connection-string-examples}

**Windows**：
`Driver={driver name};SERVER=host;PORT=10014;Database=db;UID=user`

> 示例：`Driver={AspenTech SQLplus};HOST=ip21-server;PORT=10014;MAXROWS=12000000`

**类 UNIX 系统**：
`Driver=/path/to/driver.so;SERVER=host;PORT=10014;Database=db;UID=user`

> 示例：`Driver=/opt/lib/libmsodbcsql.18.dylib;SERVER=localhost;Database=test`

:::tip macOS 设置

1. 安装 unixodbc：`brew install unixodbc`
2. 验证安装：`odbcinst -j`
3. 列出驱动程序：`cat /opt/homebrew/etc/odbcinst.ini`
   :::

### 驱动程序安装 {#driver-installation}

| 平台       | 安装方法                                     |
| ---------- | -------------------------------------------- |
| Windows    | 使用 ODBC 数据源管理器配置驱动程序           |
| UNIX/Linux | 安装驱动程序，然后在连接字符串中指定完整路径 |
| macOS      | `brew install unixodbc` + 安装驱动程序       |

### Aspen IP21 配置 {#aspen-ip21-configuration}

为获得最佳 IP21 性能：

1. 将 OIBus 安装在 IP21 机器上，或至少安装在同一本地网络中（SQLplus 驱动程序对网络延迟很敏感）
2. 在 OIBus 机器上安装 `AspenTech SQLplus` ODBC 驱动程序
3. 使用连接字符串：`Driver={AspenTech SQLplus};HOST=<host>;PORT=10014;MAXROWS=12000000`

:::caution 认证

- 连接字符串中的密码以纯文本形式存储。请改用**密码**字段。
- 对于本地认证，请确保 OIBus 服务以适当的权限运行

:::

:::note ODBC 日期时间字段类型
以下**类型**值可用于跟踪的时刻的日期时间字段：

| 类型              | 描述                                               |
| ----------------- | -------------------------------------------------- |
| 字符串            | 使用自定义格式解析的字符串表示形式                 |
| ISO 字符串        | ISO 8601 字符串（例如 `2024-01-15T10:30:00.000Z`） |
| UNIX 纪元（秒）   | 以秒为单位的 Unix 时间戳                           |
| UNIX 纪元（毫秒） | 以毫秒为单位的 Unix 时间戳                         |

:::
