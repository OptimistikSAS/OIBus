# OLEDB

通过远程 [OIBus Agent](../oibus-agent/oledb.md) 连接到 OLEDB 数据源。特别适用于 OSIsoft PI System™
等系统以及其他兼容 OLEDB 的应用程序。

:::info 兼容性说明

- 需要在目标计算机上安装 OIBus Agent
- 支持所有兼容 OLEDB 的数据源
- 针对 OSIsoft PI System™ 连接进行了优化

:::

## 特定设置 {#specific-settings}

| 设置           | 描述                                                                                                                                              | 示例值                                      |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| 远程 Agent URL | Agent 端点 URL。所有连接均为必填项。                                                                                                              | `http://192.168.1.100:2224`                 |
| 连接超时       | 建立连接的最长时间（毫秒）。默认：`15000`。                                                                                                       | `15000`                                     |
| 重试间隔       | 重试连接前等待的时间（毫秒）。默认：`10000`。                                                                                                     | `10000`                                     |
| 请求超时       | 单个查询的最长执行时间（毫秒）。默认：`15000`。                                                                                                   | `15000`                                     |
| 连接字符串     | 特定于提供程序格式的 OLEDB 连接字符串。                                                                                                           | `Provider=OraOLEDB.Oracle;Data Source=mydb` |
| 密码           | 身份验证密码（安全存储）。始终以 `Password=<password>;` 的形式附加——如果连接字符串已包含自己的 `Password=` 项，请从此处或字符串中删除以避免重复。 | `••••••••`                                  |

:::note OLEDB 日期时间字段类型
以下**类型**值可用于跟踪的时刻的日期时间字段：

| 类型              | 描述                                               |
| ----------------- | -------------------------------------------------- |
| 字符串            | 使用自定义格式解析的字符串表示                     |
| ISO 字符串        | ISO 8601 字符串（例如 `2024-01-15T10:30:00.000Z`） |
| UNIX 纪元（秒）   | 以秒为单位的 Unix 时间戳                           |
| UNIX 纪元（毫秒） | 以毫秒为单位的 Unix 时间戳                         |

:::

:::info 通过 OIBus Agent
Agent 以文本形式返回各行：跟踪字段为 UTC 时间的 ISO 8601 字符串（例如 `2024-01-15T10:30:00.000Z`），其他每一列按数据库
驱动程序呈现的形式返回，空值或 null 值返回为 `null`。请使用记录列表转换器在下游对其进行格式化
（例如[文件](../engine/transformers.mdx#file-from-records)转换器）。
:::
