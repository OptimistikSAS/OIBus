# 文件夹扫描器

**Folder Scanner（文件夹扫描器）** South 连接器会根据其项目中定义的**正则表达式（Regexp）**，
定期扫描指定的输入文件夹以查找新文件。匹配的文件将被传输到 North 缓存。

## 特定设置 {#specific-settings}

| 设置                | 说明                                                                                                                                                       | 示例值                        |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------ |
| Input folder        | 要扫描的文件夹路径。可以是**绝对路径**或**相对路径**（相对于**数据文件夹**——参见 _About_ 部分）。支持远程路径（例如 `/remote.server/data` 或 `Z:\Remote disk\DATA`）。**区分大小写**。 | `/data/input` 或 `Z:\Files`     |
| Enable compression  | 启用后，文件在发送到 North 缓存之前会使用 **gzip** 压缩。                                                                                                    | Enabled/Disabled               |

:::caution 用户访问权限要求

运行 OIBus 的用户（终端用户或服务账户）**必须拥有对输入文件夹的读取权限**。如果禁用了 **Preserve file**，
还需要**写入权限**才能删除文件。

:::

### 网络共享身份验证（仅限 Windows） {#network-share-authentication-windows-only}

要扫描 Windows 网络共享，请将 **Input folder** 设置为 UNC 路径（`\\server\share\...`）并为其提供凭据：

| 设置             | 说明                                             | 示例值        |
| ---------------- | ------------------------------------------------ | ------------- |
| **SMB username** | 用于对网络共享进行身份验证的用户名。               | `svc_oibus`   |
| **SMB password** | SMB 用户名对应的密码。                            | `••••••••`    |
| **SMB domain**   | SMB 用户名所属的域（可选，例如用于 Active Directory）。 | `CORP`        |

:::info 仅限 Windows
这些字段仅在 OIBus 运行于 Windows 时显示。OIBus 会在扫描前针对服务器建立 SMB 会话身份验证
（`net use`），并在连接器断开连接时移除该会话。此过程不经过 Windows 凭据管理器，因此当 OIBus
作为 Windows 服务运行时也能正常工作——在这种情况下，仅限交互式会话的凭据管理器即使在原本对该
共享具有访问权限的账户下也不可靠。
:::

## 项目设置 {#item-settings}

| 设置                    | 说明                                                                                                     | 示例值                                     |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| RegExp                  | 用于过滤文件的正则表达式。                                                                                  | `.*\.csv\|.*\xlsx` → CSV 或 Excel 文件       |
| Minimum age             | 文件被检索所需的最小存在时间（毫秒）。用于避免检索仍在写入中的损坏文件。默认值：`1000` 毫秒。                | `1000`                                       |
| Preserve file           | 启用后，文件在检索后**不会被删除**。适用于其他应用程序仍需要访问该文件的情况。OIBus 会跟踪修改时间，以避免重复检索未更改的文件。 | Enabled/Disabled                             |
| Ignored modified date   | （_需要启用 **Preserve file**_）即使文件的修改时间未发生变化，也强制进行检索。适用于确保文件始终被处理的场景。 | Enabled/Disabled                             |
| Max files per scan      | 每次扫描检索的最大文件数。设置为 **0** 表示无限制。剩余文件将在下一次扫描中检索。                             | `0`（无限制）、`100`                          |
| Max size per scan       | 每次扫描检索的文件总大小上限（MB）。设置为 **0** 表示无限制。剩余文件将在下一次扫描中检索。                    | `0`（无限制）、`500`                          |
| Scan sub-folders        | 启用后，将递归扫描输入文件夹内的子文件夹。                                                                    | Enabled/Disabled                             |
