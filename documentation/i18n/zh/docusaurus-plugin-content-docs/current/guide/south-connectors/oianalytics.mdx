# OIAnalytics®

从 [OIAnalytics®](https://optimistik.com/oianalytics/) SaaS 应用程序查询时间序列数据。

## 连接设置 {#connection-settings}

## 分组设置 {#group-settings}

项目可以组织成分组。每个分组定义一个共享的扫描模式和默认的限流设置。同一分组中的项目仍然是
**依次逐个**获取的——分组只是提供各项目可以覆盖的通用默认值。

| 设置         | 描述                                                                                                         | 示例值                          |
| ------------ | ------------------------------------------------------------------------------------------------------------ | ------------------------------- |
| **名称**     | 该连接器内分组的唯一标签。                                                                                   | `Group A`                       |
| **扫描模式** | 用于采集分组中所有项目的扫描模式。                                                                           | `Every 1 min`                   |
| **限流**     | 该分组中项目继承的默认限流值（最大读取间隔、读取延迟、起始时间偏移、结束时间偏移、恢复策略、未找到数据时）。 | `3600, 200, 0, 0, oldest, keep` |

## 项目设置 {#item-settings}

每个项目都可以单独配置。项目默认从所属分组继承扫描模式和限流设置，但可以通过禁用**与组同步**
对每个设置进行单独覆盖。

### 查询参数 {#query-parameters}

**查询变量**：

- `@StartTime`：初始执行时间，会更新为结果中最近的时间戳
- `@EndTime`：当前时间（`now()`）或查询被拆分时的子区间结束时间

:::info 查询拆分
较大的时间区间会使用以下方式自动拆分为更小的块：

- **最大读取间隔**（来自[限流设置](#throttling-settings)）
- 减少服务器和网络负载
- 提升数据流的韧性
  :::

:::tip 重复的键
多次添加相同的键会将其作为值数组发送在请求中，而不是覆盖之前的值。这对于接受单个参数
多个值的端点很有用，例如下方的 `data-reference`。
:::

#### 示例：查询数据值 {#example-querying-data-values}

要在一个时间窗口内检索多个数据引用的原始值，请使用 `/api/oianalytics/data/values` 端点
和以下查询参数配置该项目：

| 键             | 值                              |
| -------------- | ------------------------------- |
| from           | `@StartTime`                    |
| to             | `@EndTime`                      |
| aggregation    | `RAW_VALUES`                    |
| data-reference | `CIP_Line_1_Acid_Tank_Level`    |
| data-reference | `CIP_Line_1_Caustic_Tank_Level` |

由于 `data-reference` 是重复的，它会以 `data-reference=CIP_Line_1_Acid_Tank_Level&data-reference=CIP_Line_1_Caustic_Tank_Level`
的形式发送，使端点能够在一次查询中返回两个储罐液位的值。

## 发送的数据 {#sent-data}

每个项目将其检索到的值作为**点记录**发送，并附带其单位：

```json
{ "pointId": "CIP_Line_1_Acid_Tank_Level", "timestamp": "2024-01-15T10:00:00.000Z", "value": 52.3, "unit": "%" }
```

要将它们写入 CSV（或 JSON）文件，请将[文件](../engine/transformers.mdx#file-from-records)转换器关联到北向连接器或历史查询：
其设置用于选择列、时间戳格式和时区、分隔符、文件名以及压缩方式。

在 3.10 之前，项目会自行写入 CSV 文件（文件名、分隔符、压缩、时间戳格式和时区）：升级会将这些设置移至每个原样发送其文件的
项目的文件转换器中。读取其文件的其他转换器会被移除，因为数据为记录列表。
