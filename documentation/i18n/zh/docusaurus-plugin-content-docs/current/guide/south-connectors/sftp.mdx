# SFTP

安全地传输并读取来自远程 SFTP 服务器的文件。

## 特定设置 {#specific-settings}

| 设置         | 描述                            | 示例值          |
| ------------ | ------------------------------- | --------------- |
| **主机**     | SFTP 服务器的 IP 地址或主机名。 | `192.168.1.100` |
| **端口**     | 连接使用的端口。默认：`22`。    | `22`            |
| **压缩文件** | 在北向处理之前启用 gzip 压缩。  | 启用/禁用       |

### 身份验证 {#authentication}

| 设置     | 描述                                         | 示例值                             |
| -------- | -------------------------------------------- | ---------------------------------- |
| 认证     | 身份验证方法。                               | `Username/Password`、`Private Key` |
| 用户名   | 用于 SFTP 身份验证的用户名。                 | `sftp_user`                        |
| 密码     | 密码（用于用户名/密码身份验证）。            | `••••••••`                         |
| 私钥路径 | PEM 格式私钥文件的路径（用于私钥身份验证）。 | `/home/user/.ssh/id_rsa`           |
| 密码短语 | 私钥的密码短语，如受保护（可选）。           | `••••••••`                         |

:::info 私钥说明

- 支持受密码短语保护的密钥
- 密钥格式：PEM
- 路径示例：`/home/user/.ssh/id_rsa` 或 `C:\Users\user\.ssh\id_rsa`

:::

## 文件检索设置 {#file-retrieval-settings}

| 设置                     | 描述                                                                                                                       | 示例值               |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------- | -------------------- |
| 远程文件夹               | SFTP 服务器上源目录的路径。                                                                                                | `/incoming/data`     |
| 用于匹配文件的正则表达式 | 文件模式过滤器（正则表达式）。                                                                                             | `.*\.txt`、`.*\.csv` |
| 最小时长                 | 文件被检索所需的最小存在时长（毫秒）。避免检索仍在写入中的损坏文件。默认：`1000` 毫秒。                                    | `1000`               |
| 保留文件                 | 如启用，检索后文件**不会被删除**。适用于其他应用程序仍需访问该文件的情况。OIBus 会跟踪修改时间以避免重复检索未变更的文件。 | 启用/禁用            |
| 忽略修改日期             | （_需要启用 **保留文件**_）即使文件的修改时间未变化也强制检索。用于确保文件始终被处理。                                    | 启用/禁用            |
| 每次扫描的最大文件数     | 每次扫描检索的最大文件数。设为 **0** 表示不限制。剩余文件将在下一次扫描中检索。                                            | `0`（不限制）、`100` |
| 每次扫描的最大大小       | 每次扫描检索文件的最大总大小（MB）。设为 **0** 表示不限制。剩余文件将在下一次扫描中检索。                                  | `0`（不限制）、`500` |
| 扫描子文件夹             | 如启用，将递归扫描远程文件夹中的子文件夹。                                                                                 | 启用/禁用            |
