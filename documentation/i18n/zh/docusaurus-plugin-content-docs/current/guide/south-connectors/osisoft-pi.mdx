# OSIsoft PI System™

读取 PI Data Archive 的记录值。OIBus 通过安装在 OIBus 计算机上的 PI AF Client 访问它，借助随 OIBus 一起提供的小型
Windows 辅助进程：无需 OIBus Agent。

:::caution 系统要求

- 使用此连接器时，OIBus **必须**运行在 Windows x64 上。
- OIBus 计算机上**必须**安装 **PI AF Client**。它安装 OIBus 加载的 AF SDK，并保存已知服务器表：OIBus 可以连接的
  PI Data Archive 以及默认服务器。OIBus 不附带任何 AVEVA 软件：请根据您与 AVEVA 签订的协议，从 AVEVA 安装
  PI AF Client。
- 运行 OIBus 的 Windows 账户**必须**通过[映射或信任](#pi-af-client-configuration)对 PI Data Archive 拥有读取权限。
- AVEVA 要求任何读取 PI 数据的非 AVEVA 程序（包括 OIBus）拥有 **PI System Access (PSA)** 许可证。

:::

## 连接设置 {#connection-settings}

| 设置            | 描述                                                                                         | 示例值       |
| --------------- | -------------------------------------------------------------------------------------------- | ------------ |
| PI Data Archive | PI AF Client 已知服务器表中的 PI Data Archive 名称。留空：使用该表中的默认 PI Data Archive。 | `MYPISERVER` |
| 重试间隔        | 重试连接前等待的时间（毫秒）。默认：`10000`。                                                | `10000`      |

:::note 连接
OIBus 在连接器启动时进行连接，并每隔 **重试间隔** 重试，直到成功。与 PI Data Archive 的连接中断时，正在进行的读取
会失败，下一次读取将重新连接。
:::

## 分组设置 {#group-settings}

项目被组织成**分组**。每个分组定义一个共享的扫描模式以及历史数据检索的默认限流参数。

| 设置         | 描述                                 | 示例值        |
| ------------ | ------------------------------------ | ------------- |
| **名称**     | 该连接器内分组的唯一标签。           | `Group A`     |
| **扫描模式** | 应用于分组中每个项目的采集扫描模式。 | `Every 1 min` |

<ThrottlingSettings />

:::tip 按项目覆盖限流
每个项目都可以通过在项目编辑表单中禁用**与组同步**开关来覆盖分组的限流默认值。
:::

## 项目配置 {#item-configuration}

### 点访问方法 {#point-access-methods}

| 设置    | 描述                                                                                                                                                                                                           | 示例值                           |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| 类型    | 访问方法：`PI point`（按名称访问单个点）或 `PI query`（通过查询表达式访问多个点）                                                                                                                              | `PI point` 或 `PI query`         |
| PI 点位 | 精确的点名称（不含服务器名称，不区分大小写）。当类型为 `PI point` 时使用。                                                                                                                                     | `SINUSOID`                       |
| PI 查询 | 选择多个点的查询（参见 [PI Point Query Syntax](https://docs.aveva.com/bundle/af-sdk/page/html/pipoint-query-syntax-overview.htm)）。不带属性名称的查询（如 `sinus*`）会在点名称中搜索。默认值：`*`（所有点）。 | `tag:=SINUS* AND pointsource:=R` |

:::info 引用名称

- 对于 `PI point`：项目名称在 JSON 有效载荷中作为引用
- 对于 `PI query`：PI 名称用作引用
  :::

:::info 值
OIBus 读取每个时间区间起点与终点之间（含两端）的记录值。每条记录包含点位（`pointId`）、时间戳（ISO 8601 UTC 字符串）
和值：数值点为数字，数字状态为状态名称（包括系统状态，如 `I/O Timeout`），其他为字符串。下一个区间从最后读取的值之后
开始。找不到的点或失败的查询会记录为警告，其他项目仍会被读取。
:::

## PI AF Client 配置 {#pi-af-client-configuration}

### 已知服务器表 {#known-servers-table}

在 OIBus 计算机上将 PI Data Archive 添加到 PI AF Client 的已知服务器表中（例如使用 PI System Explorer，
**File** → **Connections**）；如果连接器的 **PI Data Archive** 设置留空，请将其设为默认服务器。

### 用户配置 {#user-configuration}

OIBus 使用运行它的 Windows 账户（其服务账户）进行连接，从不弹出登录提示：

1. 创建域用户账户（可从两台计算机访问）

- 如果域不存在，请创建具有相同密码的相同本地用户

2. 以该用户身份运行 OIBus 服务

### 信任配置 {#trust-configuration}

1. 打开 PI System Management Tools
2. 导航到 `Mapping & Trusts` → `Trusts` 选项卡
3. 创建新信任，包含：

- OIBus 计算机 IP 和子网掩码
- 域（如适用）
- 用于连接的 PI Identity

### 映射配置 {#mapping-configuration}

1. 在 PI System Management Tools 中
2. 导航到 `Mapping & Trusts` → `Mappings` 选项卡
3. 创建新映射，包含：

- OIBus 服务用户
- 来自信任配置的 PI Identity

:::tip 日志访问
在 PI System Management Tools 中查看系统日志：
`Operation` → `Messages Logs`
:::
