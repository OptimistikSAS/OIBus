# MySQL® / MariaDB™

使用 OIBus 连接并查询 MySQL® 或 MariaDB™ 数据库。

:::info 兼容性说明

- 支持 MySQL 5.7+
- 支持 MariaDB 10.2+

:::

## 特定设置 {#specific-settings}

| 设置           | 描述                                                                  | 示例值         |
| -------------- | --------------------------------------------------------------------- | -------------- |
| 主机           | MySQL/MariaDB 服务器的 IP 地址或主机名。                              | `192.168.1.10` |
| 端口           | 服务器端口号。默认值：`3306`。                                        | `3306`         |
| 连接超时       | 建立连接的最长时间（毫秒）。默认值：`5000`。                          | `5000`         |
| 数据库         | 要连接的数据库名称。                                                  | `production`   |
| 用户名         | 认证用户名。                                                          | `db_user`      |
| 密码           | 认证密码。                                                            | `••••••••`     |
| 空闲连接超时   | 连接池中未使用的连接在关闭前保持打开的时间（毫秒）。默认值：`30000`。 | `30000`        |
| 最大并行查询数 | 同时查询的项目或分组的最大数量，从 `1`（串行）到 `8`。默认值：`1`。   | `2`            |

:::note 并行查询
OIBus 维护一个最多包含该数量数据库连接的连接池，连接在查询需要时打开，并在空闲连接超时后关闭：每个连接都会增加数据源的负载。请将该值控制在服务器为该用户提供的 `max_connections` 额度之内。
:::

:::caution 用户权限

始终使用只读数据库用户

:::

## 浏览数据表 {#exploring-tables}

点击 **浏览** 可浏览数据库的表（附带列数，以及在数据库提供时的近似行数）和每个表的列，包括列的类型，以及在可获取时的
是否可为空、主键和默认值。勾选表或列后点击 **添加为项**，即可为每个表创建一个项目，其查询读取所勾选的列，并基于自动
选取的日期/时间列进行跟踪——参见 [SQL 表作为项目](./common-settings.md#sql-tables-as-items)。

此连接器上的[项同步](./common-settings.md#items-synchronisation)会运行一个元数据查询并将其结果行推送到 OIAnalytics；
它从不创建项目。

<ItemSettings />

:::note MySQL / MariaDB 日期时间字段类型
以下**类型**值可用于跟踪的时刻的日期时间字段：

| 类型              | 描述                                               |
| ----------------- | -------------------------------------------------- |
| 字符串            | 使用自定义格式解析的字符串表示形式                 |
| DateTime          | MySQL `DATETIME` 或 `TIMESTAMP` 列                 |
| ISO 字符串        | ISO 8601 字符串（例如 `2024-01-15T10:30:00.000Z`） |
| UNIX 纪元（秒）   | 以秒为单位的 Unix 时间戳                           |
| UNIX 纪元（毫秒） | 以毫秒为单位的 Unix 时间戳                         |

:::

:::note MySQL 项目请求超时
每个 MySQL 项目都有自己的**请求超时**字段（毫秒），用于设置该
项目查询的最长执行时间。没有可覆盖它的连接级别等效设置 —— **连接超时**
仅限定 OIBus 等待建立连接本身的时间，而不限定查询可运行多久。
:::
