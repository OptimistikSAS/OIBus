# MySQL® / MariaDB™

使用 OIBus 连接并查询 MySQL® 或 MariaDB™ 数据库。

:::info 兼容性说明

- 支持 MySQL 5.7+
- 支持 MariaDB 10.2+

:::

## 特定设置 {#specific-settings}

| 设置            | 描述                                                            | 示例值  |
| ------------------ | ---------------------------------------------------------------------- | -------------- |
| Host               | MySQL/MariaDB 服务器的 IP 地址或主机名。                    | `192.168.1.10` |
| Port               | 服务器端口号。默认值：`3306`。                                   | `3306`         |
| Connection timeout | 建立连接的最长时间（毫秒）。默认值：`5000`。 | `5000`         |
| Database           | 要连接的数据库名称。                                    | `production`   |
| Username           | 认证用户名。                                               | `db_user`      |
| Password           | 认证密码。                                               | `••••••••`     |

:::caution 用户权限

始终使用只读数据库用户

:::

:::note MySQL / MariaDB 日期时间字段类型
以下**类型**值可用于跟踪时刻的日期时间字段：

| Type            | Description                                       |
| --------------- | ------------------------------------------------- |
| String          | 使用自定义格式解析的字符串表示形式 |
| DateTime        | MySQL `DATETIME` 或 `TIMESTAMP` 列            |
| ISO String      | ISO 8601 字符串（例如 `2024-01-15T10:30:00.000Z`） |
| UNIX epoch (s)  | 以秒为单位的 Unix 时间戳                          |
| UNIX epoch (ms) | 以毫秒为单位的 Unix 时间戳                    |

:::

:::note MySQL 条目请求超时
每个 MySQL 条目都有自己的**请求超时**字段（毫秒），用于设置该
条目查询的最长执行时间。没有可覆盖它的连接级别等效设置 —— **连接超时**
仅限定 OIBus 等待建立连接本身的时间，而不限定查询可运行多久。
:::
