# 西门子® S7

S7 南向连接器通过 **ISO-on-TCP**（RFC1006）使用西门子® S7 通信协议，直接从西门子 S7-200/300/400/1200/1500
PLC 读取数据。它会在每次扫描模式触发时查询 PLC 内存（数据块、输入、输出、标志位、定时器、计数器），
无需经过 OPC 服务器或单独的 Agent。

OIBus 通过自带的 S7 客户端与 PLC 通信，该客户端源自采用 MIT 许可证的
[nodeS7](https://github.com/plcpeople/nodeS7) 库：无需安装任何驱动程序。

## 特定设置 {#specific-settings}

| 设置         | 描述                                                                                                                                                    | 示例值          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- |
| **主机**     | PLC 的 IP 地址或主机名。                                                                                                                                | `192.168.1.100` |
| **端口**     | 要连接的 ISO-on-TCP 端口（部分网关使用 502，但西门子 PLC 通常使用 `102`）。                                                                             | `102`           |
| **连接类型** | OIBus 向 PLC 呈现的 TSAP（传输服务访问点）身份：`PG`（编程设备）、`OP`（操作面板）或 `S7 Basic`。必须与 PLC 的连接机制/安全设置所允许的连接类型相匹配。 | `S7 Basic`      |
| **机架**     | CPU 在其机架中的机架号。对于 S7-1200/1500 及独立 CPU，通常为 `0`。                                                                                      | `0`             |
| **插槽**     | CPU 在其机架中的插槽号。对于 S7-1200/1500 通常为 `1`，对于 S7-300/400 通常为 `2`。                                                                      | `1`             |
| **连接超时** | 建立连接时等待的最长时间（毫秒）。                                                                                                                      | `10000`         |
| **请求超时** | 等待读取请求响应的最长时间（毫秒）。                                                                                                                    | `15000`         |
| **重试间隔** | 连接失败或意外断开后，重试前等待的时间（毫秒）。                                                                                                        | `10000`         |

:::tip 连接类型、机架和插槽
在 S7-1200/1500 CPU 上，TIA Portal 中的**保护与安全 &gt; 连接机制**设置控制着允许哪些连接类型
（PG/OP/S7 Basic）——如果 OIBus 无法连接，请检查所选的**连接类型**是否在该处被允许。
**机架**/**插槽**取决于 CPU 型号及其物理/虚拟位置；如果默认值不起作用，请查阅您的 PLC 文档。
:::

## 项目设置 {#item-settings}

每个项目只有一个**地址**设置：

| 设置     | 描述                                        | 示例值      |
| -------- | ------------------------------------------- | ----------- |
| **地址** | 要读取的 PLC 内存地址，使用下文所述的语法。 | `DB1,REAL0` |

### 地址语法 {#address-syntax}

在数据块中，地址的格式为 `DB<n>,<type><offset>[.<位或长度>][.<数组长度>]`：

- **`DB<n>,`** ——数据块编号（例如 `DB1,`）。
- **`<type>`** ——要在该偏移量处读取的数据类型（见下表）。
- **`<offset>`** ——数据块内的字节偏移量。
- **`.<位或长度>`** ——对于 `X`，表示位偏移量（`0`–`7`）；对于 `STRING`，表示其在 PLC 中声明的最大长度
  （`STRING[20]` 为 `20`）；对于其他类型，表示可选的数组长度，用于读取若干个连续的值。
- **`.<数组长度>`** ——仅适用于 `X` 和 `STRING`，表示可选的数组长度。

| 类型           | 别名               | 大小（字节） | 值                                                      |
| -------------- | ------------------ | ------------ | ------------------------------------------------------- |
| `X`            | `BOOL`             | 1 位         | `true` 或 `false`                                       |
| `BYTE`         | `B`、`USINT`       | 1            | 0 到 255                                                |
| `SINT`         |                    | 1            | -128 到 127                                             |
| `CHAR`         | `C`                | 1            | 一个字符。字符数组作为一个文本读取                      |
| `WORD`         | `W`、`UINT`        | 2            | 0 到 65,535                                             |
| `INT`          | `I`                | 2            | -32,768 到 32,767                                       |
| `DWORD`        | `D`、`DW`、`UDINT` | 4            | 32 位无符号整数                                         |
| `DINT`         | `DI`               | 4            | 32 位有符号整数                                         |
| `REAL`         | `R`                | 4            | 32 位浮点数                                             |
| `LREAL`        | `LR`               | 8            | 64 位浮点数                                             |
| `LINT`         | `LI`               | 8            | 64 位有符号整数                                         |
| `ULINT`        | `LWORD`            | 8            | 64 位无符号整数                                         |
| `STRING`       | `S`                | 最大长度 + 2 | 文本                                                    |
| `DT` / `DTZ`   |                    | 8            | `DATE_AND_TIME`，按 OIBus 所在机器的本地时间 / UTC 读取 |
| `DTL` / `DTLZ` |                    | 12           | `DTL`，按 OIBus 所在机器的本地时间 / UTC 读取           |

在数据块之外，地址的格式为 `<区域><type><offset>[.<位或数组长度>][.<数组长度>]`：

- **`<区域>`** ——`M`（Merker 标志位）、`I`/`E`（输入）、`Q`/`A`（输出）、`PI`/`PE`/`PQ`/`PA`（外设输入和输出，
  直接从模块读取，而不是从过程映像读取）。
- **`<type>`** ——单个位不加类型，且需要位偏移量（`M32.2`）；或者 `B`（`BYTE`）、`C`（`CHAR`）、`W`（`WORD`）、
  `I`（`INT`）、`D`/`DW`（`DWORD`）、`DI`（`DINT`）、`R`（`REAL`）、`LR`（`LREAL`）、`LI`（`LINT`）。

定时器和计数器按编号寻址：`T<n>` 和 `C<n>`，可带数组长度（`C0.4` 读取计数器 0 到 3），返回其原始 16 位字。
地址不区分大小写。

| 地址           | 含义                                                |
| -------------- | --------------------------------------------------- |
| `DB1,REAL0`    | 数据块 1 中字节偏移量 0 处的单个 `REAL`（浮点数）。 |
| `DB1,INT2`     | 数据块 1 中字节偏移量 2 处的单个 `INT`。            |
| `DB1,X4.0`     | 数据块 1 中字节偏移量 4、位 0 处的单个位。          |
| `DB1,X4.0.8`   | 数据块 1 中字节 4 的 8 个位。                       |
| `DB1,REAL0.20` | 从字节偏移量 0 开始的 20 个 `REAL` 值组成的数组。   |
| `DB1,S10.20`   | 数据块 1 中字节偏移量 10 处的一个 `STRING[20]`。    |
| `M32.2`        | Merker 存储器中字节偏移量 32、位 2 处的单个位。     |
| `MR4`          | Merker 存储器中字节偏移量 4 处的单个 `REAL`。       |
| `IW2`          | 字节偏移量 2 处的输入字。                           |
| `PIW256`       | 字节偏移量 256 处的外设输入字。                     |
| `T3`           | 定时器 3。                                          |

:::note 值以文本形式读取
无论 PLC 的数据类型是什么，OIBus 都会将每个 S7 项目的值报告为字符串（例如 `"3.14"`、`"true"`）。
数组以逗号分隔的值表示（`"1.5,2.5,3.5"`），日期以 ISO 8601 UTC 格式表示（`"2024-03-15T11:34:56.789Z"`）。
在配置下游的转换器或北向连接器时请考虑到这一点。
:::

:::tip 分组读取
OIBus 以尽可能少的请求读取一个扫描模式的所有项目：同一区域内相距不超过 5 个字节的项目作为一个块读取，
每个请求的大小按与 PLC 协商的 PDU 大小确定（大多数 S7-300 为 240 字节，S7-1500 最高 960 字节），
连接测试会显示该大小。PLC 无法读取的项目（数据块不存在、地址超出范围）会被记录并跳过，不影响其他项目。
:::

## 缓存策略 {#caching-strategy}

与其他 IoT 系列连接器一样，S7 项目支持按项目配置[缓存策略](./common-settings.md#caching-strategy)
（`所有值`、`变化时`、`阈值`），以过滤实际被缓存并转发的读取值。
