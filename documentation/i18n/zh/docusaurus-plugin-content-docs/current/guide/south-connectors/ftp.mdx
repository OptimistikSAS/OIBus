# FTP

安全地传输并读取来自远程 FTP 服务器的文件。

## 特定设置 {#specific-settings}

| 设置               | 描述                                | 示例值            |
| ------------------ | ------------------------------------- | ----------------- |
| **主机**           | FTP 服务器的 IP 地址或主机名。          | `192.168.1.100`   |
| **端口**           | 连接使用的端口。默认值：`21`。         | `21`               |
| **压缩文件**       | 在北向处理之前启用 gzip 压缩。      | 启用/禁用         |

### 认证 {#authentication}

| 设置                    | 描述                                                          | 示例值                       |
| ----------------------- | --------------------------------------------------------------- | ------------------------------ |
| 认证                    | 认证类型：`无`（不认证）或 `用户名/密码`。       | `无`、`用户名/密码`            |
| 用户名                  | 用于 FTP 服务器认证的用户名（使用用户名/密码认证时）。   | `ftp_user`                     |
| 密码                    | 用于 FTP 服务器认证的密码（使用用户名/密码认证时）。     | `••••••••`                     |

## 文件检索设置 {#file-retrieval-settings}

| 设置                    | 描述                                                                                                     | 示例值                    |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------- |
| 远程文件夹              | FTP 服务器上的源目录路径。                                                                                   | `/incoming/data`             |
| RegExp                  | 文件模式过滤器（正则表达式）。                                                                               | `.*\.txt`、`.*\.csv`         |
| 最小时长                | 文件被检索所需的最小存在时间（毫秒）。用于避免检索仍在写入中的损坏文件。默认值：`1000` 毫秒。                | `1000`                       |
| 保留文件                | 启用后，文件在检索后**不会被删除**。适用于其他应用程序仍需要访问该文件的情况。OIBus 会跟踪修改时间，以避免重复检索未更改的文件。 | 启用/禁用                    |
| 忽略修改日期            | （_需要启用**保留文件**_）即使文件的修改时间未发生变化，也强制进行检索。适用于确保文件始终被处理的场景。 | 启用/禁用                    |
| 每次扫描的最大文件数    | 每次扫描检索的最大文件数。设置为 **0** 表示无限制。剩余文件将在下一次扫描中检索。                             | `0`（无限制）、`100`          |
| 每次扫描的最大大小      | 每次扫描检索的文件总大小上限（MB）。设置为 **0** 表示无限制。剩余文件将在下一次扫描中检索。                    | `0`（无限制）、`500`          |
| 扫描子文件夹            | 启用后，将递归扫描远程文件夹内的子文件夹。                                                                    | 启用/禁用                    |
