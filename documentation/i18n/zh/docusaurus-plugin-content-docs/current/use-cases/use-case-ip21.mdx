# Aspen InfoPlus.21® (IP21) → Amazon S3™

## 前提条件 {#beforehand}

AspenTech IP21 是一个实时数据历史数据库，用于采集、存储和分析工业过程的时间序列数据。OIBus 通过 ODBC 连接到 IP21。

有关完整的配置详情，请参阅[北向 Amazon S3](../guide/north-connectors/aws-s3.md)和[南向 ODBC](../guide/south-connectors/odbc)连接器页面。

本使用案例需要在 OIBus 机器上安装 **AspenTech SQLplus** ODBC 驱动程序。示例使用以下虚构网络。

<div style={{ textAlign: 'center' }}>

![IP21 -> AWS S3](@site/static/img/use-cases/ip21-aws.svg)

</div>

:::caution 将 OIBus 安装在靠近 IP21 的位置
Aspen SQLplus 驱动程序对网络延迟很敏感。请将 OIBus 安装在 IP21 服务器上，或至少安装在同一本地网络中。OIBus 与历史数据库之间额外的网络跳数或防火墙可能导致数据采集问题和性能下降。
:::

## 南向 ODBC {#south-odbc}

ODBC 连接器使用 [node-odbc](https://github.com/markdirish/node-odbc) 驱动程序，它依赖于安装在 OIBus 机器上的 ODBC 驱动程序。请在运行 OIBus 的机器上安装 **AspenTech SQLplus** ODBC 驱动程序。

连接字符串遵循标准 ODBC 格式，例如 `Driver={AspenTech SQLplus};HOST=192.169.0.2;PORT=10014;MAXROWS=12000000`。

### 项目 {#items}

ODBC 连接器接受 SQL 查询。有关使用 `@StartTime` 和 `@EndTime` 变量编写查询的指导，请参阅 [MSSQL 项目文档](./use-case-mssql#sql-queries)。

## 北向 Amazon S3 {#north-amazon-s3}

在填写连接器设置之前，您需要准备以下内容：

- 存储桶：`oibus-test`
- 区域：`eu-west-3`
- 文件夹：`north-local-oib`（留空则将文件存储在存储桶根目录）
- 在 Amazon S3 中生成的访问密钥和私密密钥
