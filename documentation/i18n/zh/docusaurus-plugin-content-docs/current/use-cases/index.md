# 使用案例

本节中的使用案例通过具体的网络拓扑图、配置示例以及有关访问权限、防火墙规则和连接器调优的技巧，展示了端到端的 OIBus 部署方案。

每个使用案例都涵盖一种特定的南向 → 北向连接器组合。在跟随某个使用案例操作之前，请确保已阅读每篇指南顶部链接的相关连接器参考页面。

| 使用案例                                                       | 南向连接器                    | 北向连接器          |
| ------------------------------------------------------------- | ---------------------------- | ------------------ |
| [OPC UA → OIAnalytics](./use-case-opcua)                      | OPC UA                       | OIAnalytics        |
| [Microsoft SQL Server → Azure Blob Storage](./use-case-mssql) | MSSQL                        | Azure Blob Storage |
| [ADS / TwinCAT → OIAnalytics](./use-case-ads)                 | ADS                          | OIAnalytics        |
| [Modbus → File Writer](./use-case-modbus)                     | Modbus                       | File Writer        |
| [Aspen IP21 → Amazon S3](./use-case-ip21)                     | ODBC（通过 OIBus Agent）       | Amazon S3          |
| [OSIsoft PI → OIAnalytics](./use-case-pi)                     | OSIsoft PI（通过 OIBus Agent） | OIAnalytics        |
| [高级多网络配置](./use-case-advanced)                          | 多种                          | 多种                |

:::tip 初次使用 OIBus？
从 [OPC UA → OIAnalytics](./use-case-opcua) 使用案例开始 — 它涵盖了最常见的部署模式，并介绍了其他所有使用案例中都会用到的关键概念。
:::
