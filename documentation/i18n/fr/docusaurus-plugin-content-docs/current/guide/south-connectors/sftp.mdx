# SFTP

Transférez et lisez de manière sécurisée des fichiers depuis des serveurs SFTP distants.

## Paramètres spécifiques {#specific-settings}

| Paramètre                   | Description                                           | Exemple de valeur |
| --------------------------- | ----------------------------------------------------- | ----------------- |
| **Hôte**                    | Adresse IP ou nom d'hôte du serveur SFTP.             | `192.168.1.100`   |
| **Port**                    | Port pour la connexion. Par défaut : `22`.            | `22`              |
| **Compresser les fichiers** | Active la compression gzip avant le traitement North. | Activé/Désactivé  |

### Authentification {#authentication}

| Paramètre               | Description                                                                                  | Exemple de valeur                  |
| ----------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------- |
| Authentification        | Méthode d'authentification.                                                                  | `Username/Password`, `Private Key` |
| Nom d'utilisateur       | Nom d'utilisateur pour l'authentification SFTP.                                              | `sftp_user`                        |
| Mot de passe            | Mot de passe (pour l'authentification Nom d'utilisateur/Mot de passe).                       | `••••••••`                         |
| Chemin de la clé privée | Chemin vers le fichier de clé privée au format PEM (pour l'authentification par clé privée). | `/home/user/.ssh/id_rsa`           |
| Phrase secrète          | Phrase secrète de la clé privée, si elle est protégée (facultatif).                          | `••••••••`                         |

:::info Notes sur la clé privée

- Prend en charge les clés protégées par une phrase secrète
- Format de clé : PEM
- Exemple de chemin : `/home/user/.ssh/id_rsa` ou `C:\Users\user\.ssh\id_rsa`

:::

## Paramètres de récupération des fichiers {#file-retrieval-settings}

| Paramètre                         | Description                                                                                                                                                                                                                | Exemple de valeur     |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| Dossier distant                   | Chemin du répertoire source sur le serveur SFTP.                                                                                                                                                                           | `/incoming/data`      |
| Regex pour récupérer les fichiers | Filtre de motif de fichier (expression régulière).                                                                                                                                                                         | `.*\.txt`, `.*\.csv`  |
| Âge minimum                       | Âge minimum (en ms) requis pour qu'un fichier soit récupéré. Évite de récupérer des fichiers corrompus encore en cours d'écriture. Par défaut : `1000` ms.                                                                 | `1000`                |
| Conserver les fichiers            | Si activé, les fichiers ne sont **pas supprimés** après récupération. Utile si d'autres applications ont besoin d'y accéder. OIBus suit la date de modification pour éviter de récupérer à nouveau des fichiers inchangés. | Activé/Désactivé      |
| Ignorer la date de modification   | (_Nécessite **Conserver les fichiers**_) Force la récupération même si la date de modification du fichier n'a pas changé. Utile pour garantir que les fichiers sont toujours traités.                                      | Activé/Désactivé      |
| Fichiers max par scan             | Nombre maximum de fichiers à récupérer par scan. Réglez sur **0** pour ne pas fixer de limite. Les fichiers restants sont récupérés lors du scan suivant.                                                                  | `0` (illimité), `100` |
| Taille max par scan               | Taille totale maximale (en Mo) des fichiers par scan. Réglez sur **0** pour ne pas fixer de limite. Les fichiers restants sont récupérés lors du scan suivant.                                                             | `0` (illimité), `500` |
| Scanner les sous-dossiers         | Si activé, scanne récursivement les sous-dossiers du dossier distant.                                                                                                                                                      | Activé/Désactivé      |
