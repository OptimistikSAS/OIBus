# SQLite™

Se connecter à des fichiers de base de données SQLite™ et les interroger avec OIBus.

## Paramètres spécifiques {#specific-settings}

| Paramètre                    | Description                                              | Exemple de valeur                |
| ---------------------------- | -------------------------------------------------------- | -------------------------------- |
| Chemin de la base de données | Chemin complet vers le fichier de base de données SQLite | `C:\databases\production.sqlite` |

### Bonnes pratiques {#best-practices}

- Placez la base de données sur un support de stockage rapide (SSD recommandé)
- Évitez les écritures concurrentes depuis plusieurs processus
- Utilisez le mode WAL pour une meilleure concurrence (PRAGMA journal_mode=WAL)

## Explorer les tables {#exploring-tables}

Cliquez sur **Explorer** pour parcourir les tables de la base de données (avec leur nombre de colonnes et, lorsque la
base le fournit, un nombre approximatif de lignes) et les colonnes de chaque table, avec leur type et, lorsque
disponibles, leur nullabilité, leur clé primaire et leur valeur par défaut. Cochez des tables ou des colonnes et
cliquez sur **Ajouter comme points** pour créer un élément par table, dont la requête lit les colonnes cochées et est
suivie sur une colonne date/heure choisie automatiquement — voir
[Tables SQL comme éléments](./common-settings.md#sql-tables-as-items).

Une [synchronisation des points](./common-settings.md#items-synchronisation) sur ce connecteur exécute une requête de
métadonnées et envoie ses lignes à OIAnalytics ; elle ne crée jamais d'éléments.

:::note Types de champ date/heure SQLite
Les valeurs de **Type** suivantes sont disponibles pour le champ date/heure de l'instant suivi :

| Type             | Description                                                              |
| ---------------- | ------------------------------------------------------------------------ |
| Chaîne           | Représentation sous forme de chaîne analysée avec un format personnalisé |
| Chaîne ISO       | Chaîne ISO 8601 (par exemple `2024-01-15T10:30:00.000Z`)                 |
| Époque UNIX (s)  | Horodatage Unix en secondes                                              |
| Époque UNIX (ms) | Horodatage Unix en millisecondes                                         |

:::
