# ODBC

Se connecter à des sources de données ODBC, localement ou via un [OIBus Agent](../oibus-agent/odbc.md) distant. Particulièrement utile pour des systèmes tels qu'Aspen InfoPlus.21® (IP21) et d'autres applications compatibles ODBC.

:::info Notes de compatibilité

- Fonctionne avec toute source de données compatible ODBC
- Recommandé pour les connexions Aspen IP21
- Prend en charge les configurations de pilotes locales et distantes

:::

## Paramètres spécifiques {#specific-settings}

| Paramètre                        | Description                                                                                                                                                                                                                                          | Exemple de valeur                                 |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| Utiliser un agent distant        | Activer pour acheminer les requêtes via un OIBus Agent sur une machine distante.                                                                                                                                                                     | Activé/Désactivé                                  |
| URL de l'agent distant           | URL du point de terminaison de l'agent. Requis en cas d'utilisation d'un agent distant.                                                                                                                                                              | `http://host:2224`                                |
| Délai de connexion               | Temps maximal en millisecondes pour établir la connexion. Par défaut : `15000`.                                                                                                                                                                      | `15000`                                           |
| Intervalle de nouvelle tentative | Temps en millisecondes à attendre avant de retenter la connexion. Par défaut : `10000`.                                                                                                                                                              | `10000`                                           |
| Délai de requête                 | _(Utilisé uniquement avec **Utiliser un agent distant**)_ Temps d'exécution maximal en millisecondes pour chaque requête individuelle, envoyé à l'agent. Par défaut : `15000`. Non applicable aux connexions locales (sans agent).                   | `15000`                                           |
| Chaîne de connexion              | Chaîne de connexion ODBC dans un format spécifique au pilote.                                                                                                                                                                                        | `Driver={AspenTech SQLplus};HOST=ip21;PORT=10014` |
| Mot de passe                     | Mot de passe d'authentification (stocké de façon sécurisée). Toujours ajouté sous forme de `PWD=<password>;` — si votre chaîne de connexion contient déjà sa propre entrée `PWD=`/`Pwd=`, supprimez-la ici ou dans la chaîne pour éviter un doublon. | `••••••••`                                        |

### Exemples de chaîne de connexion {#connection-string-examples}

**Windows** :
`Driver={driver name};SERVER=host;PORT=10014;Database=db;UID=user`

> Exemple : `Driver={AspenTech SQLplus};HOST=ip21-server;PORT=10014;MAXROWS=12000000`

**Systèmes de type UNIX** :
`Driver=/path/to/driver.so;SERVER=host;PORT=10014;Database=db;UID=user`

> Exemple : `Driver=/opt/lib/libmsodbcsql.18.dylib;SERVER=localhost;Database=test`

:::tip Configuration macOS

1. Installer unixodbc : `brew install unixodbc`
2. Vérifier l'installation : `odbcinst -j`
3. Lister les pilotes : `cat /opt/homebrew/etc/odbcinst.ini`
   :::

### Installation du pilote {#driver-installation}

| Plateforme | Méthode d'installation                                                           |
| ---------- | -------------------------------------------------------------------------------- |
| Windows    | Utiliser l'administrateur de sources de données ODBC pour configurer les pilotes |
| UNIX/Linux | Installer le pilote puis indiquer le chemin complet dans la chaîne de connexion  |
| macOS      | `brew install unixodbc` + installation du pilote                                 |

### Configuration Aspen IP21 {#aspen-ip21-configuration}

Pour des performances IP21 optimales :

1. Installer OIBus Agent sur la machine IP21
2. Utiliser la chaîne de connexion : `Driver={AspenTech SQLplus};HOST=<host>;PORT=10014;MAXROWS=12000000`
3. S'assurer que le pilote `AspenTech SQLplus` est installé sur la machine de l'agent
4. Configurer le service de l'agent avec les permissions appropriées

:::caution Authentification

- Les mots de passe dans les chaînes de connexion sont stockés en texte clair. Utilisez plutôt le champ **Mot de passe**.
- Pour l'authentification locale, assurez-vous qu'OIBus Agent s'exécute avec les permissions appropriées

:::

:::note Types de champ date/heure ODBC
Les valeurs de **Type** suivantes sont disponibles pour la configuration du champ date/heure :

| Type             | Description                                                   |
| ---------------- | ------------------------------------------------------------- |
| Chaîne           | Représentation textuelle analysée avec un format personnalisé |
| Chaîne ISO       | Chaîne ISO 8601 (par ex. `2024-01-15T10:30:00.000Z`)          |
| Époque UNIX (s)  | Horodatage Unix en secondes                                   |
| Époque UNIX (ms) | Horodatage Unix en millisecondes                              |

:::
