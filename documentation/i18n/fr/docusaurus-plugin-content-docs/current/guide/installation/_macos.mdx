## Exécuter OIBus {#run-oibus}

1. Extrayez l'archive téléchargée à l'emplacement de votre choix.

2. Ouvrez le **Terminal** et accédez au dossier extrait.

3. Lancez OIBus :

```bash
./oibus-launcher --config ~/oibus-data
```

Remplacez `~/oibus-data` par le chemin où vous souhaitez stocker la configuration et les fichiers de cache d'OIBus.

:::note

- Des droits administrateur sont requis pour exécuter le binaire.
- Le binaire doit être exécuté depuis son propre dossier.
  :::

## Autoriser l'exécution de l'application {#allow-app-execution}

macOS Gatekeeper bloquera les binaires non signés au premier lancement. Vous devez autoriser à la fois `oibus-launcher`
et `oibus` (que le launcher démarre en tant que processus enfant) :

1. Exécutez `./oibus-launcher` — macOS affichera un avertissement de sécurité et bloquera l'exécution.
2. Allez dans **Réglages Système → Confidentialité et sécurité**.
3. Dans la section **Sécurité**, cliquez sur **Autoriser quand même** à côté du binaire bloqué.
4. Répétez l'opération pour le second binaire lorsqu'il est bloqué.

## Accéder à OIBus {#access-oibus}

Une fois qu'OIBus est en cours d'exécution, ouvrez `http://localhost:2223` dans un navigateur et suivez le
[guide de premier accès](./first-access.mdx).
