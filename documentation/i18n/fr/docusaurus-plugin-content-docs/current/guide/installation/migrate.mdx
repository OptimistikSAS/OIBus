## Étapes de migration {#migration-steps}

1. Arrêtez le service OIBus.
   :::tip
   Vous pouvez zipper le dossier de données, ou au moins le fichier de configuration `oibus.json` et son dossier
   `keys`, en guise de sauvegarde.
   :::

2. Installez [OIBus v3.9.6](#download-specific-version). Veillez à spécifier le **même dossier de données**. Vérifiez
   qu'OIBus v3 fonctionne correctement en vous connectant sur `http://localhost:2223` avec admin / pass. Si tout
   fonctionne, passez à l'étape suivante.

3. Arrêtez OIBus v3.

4. Copiez l'outil de migration dans le **dossier binaire** d'OIBus.

5. Exécutez l'outil de migration OIBus. Veillez à spécifier le dossier de données approprié.

**Commande Windows**

```
oibus-upgrade.exe --config D:\OIBusData
```

**Commande Linux / macOS**

```
./oibus-upgrade --config /usr/oibus/OIBusData
```

6. Démarrez OIBus v3.

:::tip
Le fichier `upgrade-journal.log` contient les journaux de la migration.
:::

:::info Ce qui est migré

- Les paramètres du moteur, les filtres IP et l'utilisateur admin (il remplace l'utilisateur `admin` par défaut d'OIBus v3).
- Les modes de scan utilisés par les connecteurs South.
- Les connecteurs South et leurs points. Les points des connecteurs OPC UA, OPC HDA, Modbus et ADS sont regroupés en
  groupes, un par mode de scan. Le chevauchement des connecteurs d'historique devient un décalage de l'heure de début
  négatif.
- Le dernier instant traité des connecteurs South d'historique, ainsi que les fichiers déjà traités par les scanners de
  dossier qui conservent leurs fichiers.
- Les connecteurs North, leurs abonnements, et les données en attente dans leurs dossiers de cache, d'erreurs et
  d'archive.
  :::
