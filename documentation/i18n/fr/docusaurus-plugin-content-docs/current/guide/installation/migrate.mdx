## Étapes de migration {#migration-steps}

1. Arrêtez le service OIBus.
   :::tip
   Vous pouvez zipper le dossier de données, ou au moins le fichier de configuration `oibus.json` et son dossier
   `keys`, en guise de sauvegarde.
   :::

2. Installez [OIBus v3.8.8](#download-specific-version). Veillez à spécifier le **même dossier de données**. Vérifiez
   qu'OIBus v3 fonctionne correctement en vous connectant sur `http://localhost:2223` avec admin / pass. Si tout
   fonctionne, passez à l'étape suivante.

3. Arrêtez OIBus v3.

4. Copiez l'outil de migration dans le **dossier binaire** d'OIBus.

5. Exécutez l'outil de migration OIBus. Veillez à spécifier le dossier de données approprié.

**Commande Windows**

```
oibus-upgrade.exe --config D:\OIBusData
```

**Commande Linux / macOS**

```
./oibus-upgrade --config /usr/oibus/OIBusData
```

6. Démarrez OIBus v3.

:::tip
Le fichier `upgrade-journal.log` contient les journaux de la migration.
:::
