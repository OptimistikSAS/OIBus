# Aspen InfoPlus.21® (IP21) → Amazon S3™

## Préalable {#beforehand}

AspenTech IP21 est un historien de données temps réel qui collecte, stocke et analyse les données de séries temporelles issues des processus industriels. OIBus se connecte à IP21 via ODBC.

Consultez les pages des connecteurs [North Amazon S3](../guide/north-connectors/aws-s3.md) et [South ODBC](../guide/south-connectors/odbc) pour tous les détails de configuration.

Ce cas d'usage nécessite le pilote ODBC **AspenTech SQLplus** sur la machine OIBus. L'exemple utilise le réseau fictif suivant.

<div style={{ textAlign: 'center' }}>

![IP21 -> AWS S3](@site/static/img/use-cases/ip21-aws.svg)

</div>

:::caution Installez OIBus à proximité d'IP21
Le pilote Aspen SQLplus est sensible à la latence réseau. Installez OIBus sur le serveur IP21, ou au moins sur le même réseau local. Des sauts réseau ou pare-feu supplémentaires entre OIBus et l'historien peuvent provoquer des problèmes de collecte de données et une dégradation des performances.
:::

## South ODBC {#south-odbc}

Le connecteur ODBC utilise le pilote [node-odbc](https://github.com/markdirish/node-odbc), qui s'appuie sur les pilotes ODBC installés sur la machine OIBus. Installez le pilote ODBC **AspenTech SQLplus** sur la machine exécutant OIBus.

La chaîne de connexion suit le format ODBC standard, par exemple `Driver={AspenTech SQLplus};HOST=192.169.0.2;PORT=10014;MAXROWS=12000000`.

<div style={{ textAlign: 'center' }}>

![Paramètres ODBC](@site/static/img/use-cases/odbc-settings.png)

</div>

:::tip Test de la connexion
Cliquez sur **Tester les paramètres** pour vérifier la connexion avant d'enregistrer.
:::

### Éléments {#items}

Le connecteur ODBC accepte les requêtes SQL. Consultez la [documentation des éléments MSSQL](./use-case-mssql#sql-queries) pour des conseils sur l'écriture de requêtes avec les variables `@StartTime` et `@EndTime`.

## North Amazon S3 {#north-amazon-s3}

Vous avez besoin des éléments suivants avant de renseigner les paramètres du connecteur :

- Bucket : `oibus-test`
- Région : `eu-west-3`
- Dossier : `north-local-oib` (laisser vide pour stocker les fichiers à la racine du bucket)
- Clé d'accès et clé secrète générées dans Amazon S3
