## North OIAnalytics {#north-oianalytics}

Avant de configurer le connecteur, vérifiez qu'OIAnalytics est accessible depuis la machine hébergeant OIBus : ouvrez un navigateur sur la machine OIBus et accédez à l'URL d'OIAnalytics (par exemple `https://instance.oianalytics.fr`). Si la page ne se charge pas, demandez à votre équipe informatique d'autoriser la connexion — le problème vient généralement d'une règle de pare-feu sur le nom de domaine ou, plus rarement, d'une règle de port sur le HTTPS/443.

Pour une meilleure expérience, [enregistrez OIBus auprès d'OIAnalytics](../guide/installation/oianalytics.mdx) avant de créer le connecteur. Une fois l'enregistrement effectué, activez le bouton **Utiliser l'enregistrement OIAnalytics** dans les paramètres du connecteur afin que les identifiants soient gérés automatiquement.
