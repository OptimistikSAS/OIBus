# OSIsoft PI System™ → OIAnalytics®

## Avant de commencer {#beforehand}

OSIsoft PI System™ est une plateforme de gestion de données en temps réel largement utilisée dans l'industrie manufacturière, l'énergie et les services publics pour collecter, stocker et analyser des données temporelles issues de processus industriels.

Consultez les pages des connecteurs [North OIAnalytics](../guide/north-connectors/oianalytics) et [South OSIsoft PI](../guide/south-connectors/osisoft-pi) pour tous les détails de configuration.

Ce cas d'usage nécessite un [OIBus Agent](../guide/oibus-agent/installation). Installez-le soit sur le serveur PI lui-même, soit sur une autre machine sur laquelle le SDK OSIsoft PI est installé — voir [configuration du SDK OSIsoft PI](../guide/south-connectors/osisoft-pi#osisoft-pi-sdk-configuration) pour plus de détails. ### Items {#items}

Les items PI peuvent être de deux types :

- **PI point** — récupère les valeurs temporelles d'un seul point PI.
- **PI query** — récupère les valeurs temporelles de tous les points PI correspondant à une expression de type regex. Le nom de l'item n'est utilisé qu'à des fins de journalisation ; les données sont étiquetées avec les références réelles des points PI.
